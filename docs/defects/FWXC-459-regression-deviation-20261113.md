[云效缺陷](https://devops.aliyun.com/projex/bug/FWXC-459)；2026-11-13官方API创建及正文/真实截图回读确认。来源：FWXC-359的2026-11-12实测，未新发业务任务。

**现象**

Agent按第2张打开已保存处理图时选中了原始版本

**前置步骤**

生产app.cinlink.ai，Chrome有头，yabinc18。项目9ccba5a7-6b36-4630-9923-15e60a10b0c6；会话https://app.cinlink.ai/c/f6e09d59-d6a2-47d7-a104-ee445d1cccdf 。按纸船11.png、群鸟JPEG、水彩图顺序登记。纸船和群鸟各完成一次去背景并保存，刷新重开后确认。群鸟处理版本editor_image_731f721e39654f4f8c7c5d1d3b26bd4a，原版editor_image_a40abb57956c4da79a34e3f73df34b61。正式目标前停留第3张水彩图。

**提示词**

打开本会话第2张图片，仅查看，不修改

**复现步骤**

1. 导出第2张已保存去背景版作为独立基线。
2. 回到第3张，发送原完整提示词一次。
3. 出现两个工程的澄清时，选择已登记的独立群鸟同名工程并继续。
4. 核对实际画布、选中历史并导出PNG，与去背景基线比较。

**实际结果**

115秒Editor open完成，顺序解析正确，实际已从水彩切到群鸟；但选中带背景原图。处理基线1000×666、322744字节，548980个全透明像素；实际打开导出1000×666、1251382字节、Alpha全255，无全透明像素。两个原/处理历史仍在。

**预期结果**

应命中该图片正式请求前已核实的已保存处理版，保持当前保存版本上下文；不因自然顺序打开回退到原图。

**影响**

用户看到的不是已保存处理结果，容易误认编辑丢失或在错误版本继续操作。
