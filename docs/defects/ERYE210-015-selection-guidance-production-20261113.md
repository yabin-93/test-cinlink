# 【生产环境】【ERYE210-015】未选片段时分割按钮禁用，但缺少“请先选择片段”原因提示

云效：[FWXC-493](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=e5fffc8428963d66f61e42d154)；2026-11-13通过官方OpenAPI直接新建，不做历史去重。状态🤔AI提缺陷，负责人牛诗晴，重构10-29，生产环境，优先级低、严重程度4-轻微。

前置步骤三条，详细复现及验证边界单列。2张真实截图已上传并嵌入，共5个附件；正文、字段、附件ID/名称/字节数及图片引用回读通过。用例ERYE210-015保持Failed。[执行报告](../cases/requirements/ERYE-210/results-011-015-prod-20261113.md#erye210-015)。

**现象**

未选择时间线片段时，“分割所选片段”按钮正确禁用，但悬停和页面没有“请先选择片段”或等价原因提示，用户无法明确知道恢复操作需要先选择片段。

**前置步骤**

1. Windows / Google Chrome登录生产环境https://app.cinlink.ai，账号具有视频工程编辑权限。
2. 新建专用测试项目、独立会话及可写工程，准备附件20秒原片及字幕，保存并保持视频未分割。
3. 进入Scripts/文稿，暂停在12秒，点击时间线空白或按Esc清除片段选中状态。

**提示词**

无Agent提示词；本例通过页面选择片段、分割和撤销，无补槽、无目标run。

**复现步骤**

1. 打开新建工程并进入Scripts/文稿，确认原视频为一段0～20秒片段。
2. 将播放头置于12秒并暂停，按Esc清除片段选区，确认时间线没有选中片段。
3. 检查时间线工具栏“分割所选片段”按钮：按钮禁用；将鼠标悬停，查看提示和页面说明。
4. 实际只有“分割所选片段”操作名，没有“请先选择片段”或等价原因提示；未误作用于整片。
5. 作为对照，单击时间线中的原视频片段，确认选中原视频，必要时再把播放头置于12秒；按钮恢复可用。
6. 点击“分割所选片段”，确认同一原片被正确分为0～12秒及12～20秒，两段在时间线从0秒、12秒开始；保存版本1→2。
7. 点击一次撤销，确认恢复原始单片段，完整保存内容一致，版本3。

**实际结果**

缺选区时有禁用保护，但仅显示操作名“分割所选片段”，没有选择片段的原因引导；本次悬停未发现额外tooltip，附件JSON保存按钮状态及提示文本。

选中片段后按钮恢复可用，12秒分割和一次撤销均正常。因此本缺陷仅为缺少选区原因提示，不是分割错误或撤销失败。

**预期结果**

缺少片段选区时保持操作不可用，同时在悬停提示或就近说明中明确告知“请先选择片段”或等价操作前提；选中有效片段后恢复可用，不猜测整片为操作目标。

**影响**

用户看到灰色分割按钮时无法明确判断是缺少选择、权限问题还是功能暂不可用，增加操作摸索成本。
