# 【生产环境】【电商Case03】横版转竖版裁掉产品及原字幕，Reels局部修复后仍有主体缺失

云效：[FWXC-627](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=734bcbf473a246b0fe65b85187)；🤔AI提缺陷，牛诗晴，生产环境。3张失败原图已上传并嵌入，7份附件及正文回读通过。本次只同步2026-11-16既有实测，未重跑产品。

**现象**

同一横版产品视频生成Reels/TikTok后，产品主体和原画面字幕被裁切，并叠加新字幕；要求局部修复Reels后仅部分镜头修正，骑行镜头仍被裁。

**前置步骤**

1. Windows / Ego Lite登录生产环境，新建专用项目和独立会话。
2. 准备本次product-intro-300s.mp4（300秒、1280×720、英语原声、画面内英语字幕和品牌收尾），同时提供ADO产品事实表及Logo。
3. 使用同一源视频分别制作A/Reels、B/TikTok和C/Shopify，保留各自独立工程。

**提示词**

第1轮原文（电商场景!B35，整段一次发送）：

```text
我是一名品牌社媒运营，现在有一条已经制作好的 5分钟的横版产品视频，希望你帮我改成适合不同平台的三个版本：
A：Instagram Reels 版本
调整成 9:16 竖屏，时长控制在 20–30 秒。
保留原视频中最好的产品展示镜头和主要卖点。
保持品牌原有的画面风格，整体看起来简洁、精致。
调整字幕和产品位置，确保竖屏下都能完整看到。

B：TikTok 版本
调整成 9:16 竖屏，时长控制在 15–20 秒。
开头 2–3 秒直接展示产品最吸引人的功能或使用效果。
适当加快剪辑节奏，删掉不重要的内容。
添加清晰的英语字幕和结尾 CTA。

C：Shopify 商品详情页版本

保留 16:9 横屏，时长控制在 25–30 秒。
重点展示产品外观、主要功能和实际使用过程。
保留必要的产品介绍和品牌信息。
即使静音播放，也能通过画面和文字看懂产品的主要特点。

其他要求：
请优先使用原视频中的真实画面，不要随意改变产品外观和功能。
横屏转竖屏时，尽量保证产品主体完整，不要把产品的重要部分裁掉。
如果原画面不适合直接裁成竖屏，可以尝试用 AI 补充缺失的背景，让画面看起来自然，但不要改变产品本身。
三个版本分别制作，保留各自适合的平台风格，并支持后续单独修改和导出。
```

第2轮原文（电商场景!B37，整段一次发送）：

```text
Reels 版本里有几个产品展示镜头被裁掉了一部分，导致产品看起来不完整。请重新调整这些镜头的画面位置和大小，让产品能够完整显示。如果竖屏空间不够，可以尝试用 AI 补充周围的背景。保持产品本身不变，其他已经正常的镜头不要修改。
```

**复现步骤**

1. 上传前置素材，一次发送第1轮完整原文；出现“等待确认剪辑方案”时，逐个核验后原样点击“审核确认”，不手动调整构图代替应用。
2. 完成后播放实际A/B成片，检查开头和骑行段的车身、车轮、原字幕完整性及新旧字幕布局。
3. 同一会话一次发送第2轮原文，等待Reels修正版导出，保留B/C。
4. 打开修正版约8.04秒（问题段约7.3～11.27秒），核对骑行产品主体是否完整；对照B/C是否保持。

**实际结果**

A首稿26.783秒、B首稿19.300秒，均1080×1920；可见原片产品/原字幕横向被裁及新旧双层字幕。Reels修正版有部分完整镜头，但约8.04秒仍有骑行主体靠边或出框；B/C未被串改。

**预期结果**

按原文把原有文字和产品完整适配竖屏；空间不足时用缩放留边等不改变产品的方案，字幕应可读且不相互遮挡。局部修复后应覆盖已指出的产品裁切段，不误改其他正常版本。

**影响**

生成的竖版广告产品展示不完整，文字被裁或重叠，影响平台投放可读性。
