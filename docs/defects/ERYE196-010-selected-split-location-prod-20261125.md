# 【ERYE196-010】已选视频片段按自然语言分割时定位失败，未引导澄清

云效：[FWXC-768](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=3b9e443447949f49a9b452a9a3)，2026-11-25官方OpenAPI回读核验通过。

**现象**

选中唯一视频片段后，要求在片段内部第5秒分割，任务直接返回轨道/片段定位参数错误，没有引导用户补充目标。后续手动补全工程、片段及时间位置后分割成功。

**前置步骤**

1. Chrome登录CinLink生产环境，打开由处理任务返回产物后创建并保存的独立可编辑工程。
2. 工程只有一条20秒、30fps视频ERYE196-A20-30fps-marked.mp4，时间线及源范围均0～20秒、1倍速；原声、字幕及独立BGM已保存并登记基线。

**提示词**

首次指令：

在当前片段内部第5秒处分割，保留全部内容，不移动任何片段

首次失败后用于对照的补充指令：

补充定位：当前工程ERYE196-A20-30fps-marked.mp4，唯一视频轨道中的第1个视频片段，时间线0～20秒、源素材0～20秒、1倍速。只在时间线绝对5秒（片段内部第5秒）处分割，保留全部内容，不移动任何片段。

**复现步骤**

1. 在时间线选中唯一的0～20秒视频片段，发送首次指令。
2. 等待任务结束，检查提示、是否提供澄清入口，以及视频是否完成分割。
3. 首次失败后，不点击失败卡的重试；发送上述补充定位指令，检查实际分割及保存结果。

**实际结果**

首次任务已执行“读取编辑器视图”“检查编辑项目”，但“分割片段”失败，提示“轨道/片段定位参数无效；序号从1开始，定位条件与动作参数须明确。”。页面只提供重试，没有目标候选或澄清问题；视频仍为单个0～20秒片段。发送前及失败后的页面记录均显示该视频片段处于选中状态。

补充定位后46秒完成，保存重开为0～5秒和5～20秒两段，总长20秒；原声、BGM和字幕保持。实际下载成片为600帧，5秒切点前后对应原素材，声音与原声+BGM同位置对照一致。补充对照成功，不覆盖首次定位/反馈异常；不将本项描述为分割能力完全不可用。

会话：https://app.cinlink.ai/c/7438a430-91a2-4219-a100-e6e7d85d7a65

**预期结果**

能唯一确定当前片段时，正确在内部第5秒分割并保存；如果实际无法获取选中目标，应先提示用户选择片段或补充位置，明确目标后继续，不直接暴露轨道序号/工具参数错误并终止。

**影响**

用户已选片段仍无法直接完成自然语言分割，需要自行推断并补充工程名、轨道序号和时间坐标，失败提示未提供可操作的目标澄清方式。
