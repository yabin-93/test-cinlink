# 【生产环境】【ERYE210-049】关闭双水印后原生导出报错，页面未交付可下载视频

云效：[FWXC-580](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=d07993186a112f50ec9926b266)；状态🤔AI提缺陷，负责人牛诗晴，优先级高 / 2-严重。2张原图已上传并嵌入，5个附件及正文回读核验通过（2026-11-16）。

**现象**

生产环境工程中已有文字与图片两类水印，关闭总开关并保存、刷新重开确认关闭后，点击一次右上角原生“导出”，页面出现“编辑器执行数据不符合正式 v2 协议，请保留当前工程并核对服务返回。”，会话未交付可播放/下载的视频结果。

**前置步骤**

1. Windows / Google Chrome登录生产环境 https://app.cinlink.ai，账号具备视频工程编辑和导出权限。
2. 新建专用项目、独立会话及可编辑工程，导入附件E196-A.mp4（20秒、1920×1080、30fps、有原声）和E196-source-en.srt（8条英文字幕），确认视频及原声可用并已保存。
3. 工程已添加文字水印WM049及一张可正常预览的512×512 PNG图片水印；本次图片为cinlink-smoke-watermark.png，图片大小160px、不透明度75%、位置右上、边距24px，总水印开关初始开启并已保存。

**提示词**

无Agent提示词，本例全程操作页面。输入文字水印“WM049”；图片源为用例仓库assets/cinlink-smoke-watermark.png（512×512 PNG，四个彩色方块）；保持当前工程20秒及1920×1080设置，使用右上角原生导出的默认MP4流程，不虚构或要求页面没有的参数弹窗。本次没有补槽。

**复现步骤**

1. 按前置新建工程并导入20秒原片；在“媒体→聊天”导入附件英文SRT，再用对应素材卡的“添加到时间轴”操作绑定为英文原文字幕，确认时间线与字幕可见并保存。
2. 进入“水印→文字水印”，输入WM049并保存；进入“图片水印”，上传上述PNG，确认预览有效并设置/核对前置参数，保存。
3. 确认文字及图片配置均存在，然后关闭水印页的总“启用水印”开关，等待页面“已同步”。不删除文字、不移除图片源文件。
4. 刷新页面，重新进入同一工程的“水印”页，确认总开关仍关闭，WM049及图片预览仍保留，相关控件处于关闭后的禁用状态。
5. 点击右上角原生“导出”一次，不在会话输入导出提示词、不触发第二次提交。
6. 观察：页面出现红色错误“编辑器执行数据不符合正式 v2 协议，请保留当前工程并核对服务返回。”，会话没有本次可播放/下载的视频结果。
7. 保留该次任务和错误现场，沿原任务复核，不重复点击导出。确认关闭配置及源工程仍在；本轮未继续开启水印后的第二次导出。

**实际结果**

- 两类水印的总开关关闭后保存、刷新重开均保持；文字/图片引用没有因关闭而清空。
- 点击一次原生导出后页面报上述错误，用户未获得本次可播放/下载的结果。
- 原导出任务后台已为done并产生editor-export.mp4文件记录，但页面未完成交付；该状态仅辅助说明“已受理”，不能代替用户在页面取得可用视频的验收。因此本单描述为页面导出/交付失败，不断言后台没有渲染或生成文件。
- OFF视频实际画面及第二次ON导出没有完成页面验收，不将“水印仍被烧录”等未经核验的现象写成失败。

**预期结果**

关闭两类水印并保存后，原生导出应正常展示进度、完成并交付可播放/下载的MP4，不出现协议错误。交付的OFF视频不显示WM049和图片水印；源工程的两类配置仍保留，原片、字幕、原声不被改动。之后才继续开启开关并导出ON视频，核验两类水印按配置出现。

**影响**

用户无法从已关闭水印的工程正常取得导出视频，双水印开关与实际成片的完整验证及交付流程被中断。
