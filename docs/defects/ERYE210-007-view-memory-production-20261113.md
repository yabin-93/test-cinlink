**现象**

同一视频工程已停留在 Watermark/图片水印，收起编辑区后从普通入口重开，却落到文字水印页；整页刷新重开后又进入 Captions/字幕，未恢复本设备该工程的图片水印位置。

**前置步骤**

1. Windows / Google Chrome 登录生产环境 https://app.cinlink.ai，账号具有视频工程编辑权限。
2. 新建专用测试项目、独立会话和视频工程，准备附件原片（20秒、1920×1080、30fps，含原声）及附件SRT对应的8条英语字幕。
3. 工程中已有文字水印和图片水印，均已保存完成，没有待提交编辑或生成任务。

**提示词**

无 Agent 提示词；本例仅通过编辑器页面进行导航，不提交剪辑或生成任务，无补槽、无目标run。

**复现步骤**

1. 在本轮新工程准备文字水印 NAV006；再通过水印的图片入口选择一张PNG并保存。本次为logo-A.png，蓝底白字A、128×128；文字与图片水印均位于右上角，不透明度75%、边距24，作用于整段视频。
2. 点击 Watermark/水印 → 图片，确认选中图片子页、可见图片水印素材，记录当前工程标题。
3. 点击编辑区顶部“收起编辑区”，再从该会话普通“视频编辑器”入口重开；不手动切换水印子页。
4. 确认仍为同一工程，等待面板可交互并观察至少20秒；实际进入文字水印页，图片子页未选中。
5. 在同一工程整页刷新，再从普通“视频编辑器”入口进入；不手动切换模块，等待加载与恢复至少20秒。
6. 实际选中 Captions/字幕；核对工程名称仍正确，回看原视频、字幕及水印内容，确认内容未发生编辑。

**实际结果**

已选 Watermark/Image → 收起后重开为 Watermark/Text → 整页刷新后重开为 Captions。

20秒恢复轮询后仍未回到图片水印页，排除仅抓到加载瞬间默认值。工程完整保存内容与复测前一致，版本1→1；未生成、替换或删除任何素材。

**预期结果**

无显式功能入口覆盖时，普通重开和刷新重开同一工程应恢复本设备已记录的 Watermark/Image，包括图片子页；不能改成文字子页或默认字幕页。仅导航不应修改工程内容。

**影响**

离开编辑区或刷新后丢失当前水印编辑位置，用户需再次手动定位；含两类水印时容易进入与上一轮不同的编辑面板。
