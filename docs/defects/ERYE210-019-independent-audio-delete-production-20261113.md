# 【生产环境】【ERYE210-019附带发现】仅删除独立音频时，原视频及原声同区间也被裁切

云效：[FWXC-513](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=13b2ef77469fde31d9ca46f97a)；2026-11-13通过官方OpenAPI直接新建，不做历史去重。状态🤔AI提缺陷，负责人牛诗晴，重构10-29、生产环境，优先级高、严重程度2-严重。

前置三条，详细复现、实际/预期单列。1张真实失败截图上传并嵌入，原片、同一段WAV、回归准备SRT及核验JSON合计5附件；正文、字段、附件ID/名称/字节数及图片引用回读通过。

这是019独立音频删除对照中的附带异常；019混合删除仍Blocked且未执行，不因提交本缺陷改成Failed/Passed。[执行报告](../cases/requirements/ERYE-210/results-019-v2-prod-20261113.md)。

**现象**

时间线上仅选中一段独立背景音频并按Delete后，该音频被删除，但同时间范围的原视频和原声也被裁掉，20秒原片缩短为约18.61秒。

**前置步骤**

1. Windows / Google Chrome登录生产环境https://app.cinlink.ai，账号具备视频工程编辑权限。
2. 新建专用测试项目、独立会话及工程，准备附件20秒原片和完整原声（0～20秒、1倍速），本次现场另含4～6秒和10～12秒的字幕及旧配音。
3. 将附件A1-independent.wav作为独立背景音频放到14秒开始（约1.393197秒、1倍速），保持与视频/字幕/配音无联动，工程保存完成且无运行任务。

**提示词**

无Agent提示词；本次通过时间线选中音频并按Delete操作，无补槽、无目标run。

独立音频位置：时间线14.000000～15.393197秒；源范围0～1.393197秒。未使用“波纹删除”、全局时间范围裁切或其他生成指令。

**复现步骤**

1. 在新工程确认原视频和原声各为一段完整0～20秒，未拆分、未裁短；字幕及旧配音按前置保存。
2. 导入A1-independent.wav并放入独立背景音频轨，起点14秒；确认A1没有关联视频或字幕，且原视频仍为20秒。
3. 按Esc清除所有选区，单击背景音频A1片段，确认只选中“背景音乐 音频 00:14.00–00:15.39”，原视频、原声、字幕及配音均未选中。
4. 焦点保持在时间线，按一次Delete；不要按Ctrl+X，也不要选择删除时间范围或波纹删除。
5. 等待保存完成，确认A1消失；查看原视频、原声轨道和预览总时长。
6. 实际原视频及原声被拆为两段，源14～15.393197秒被裁掉，后段自动接到时间线14秒，预览总长约18.61秒。
7. 核对保存结果：变化已保存，版本3；两段旧配音音频仍在。保留失败现场，不用撤销后的页面替代截图。

**实际结果**

仅选中独立A1按Delete，A1确实被删除，但未选中的原视频和原声也同时被裁切：

- 删除前：原视频/原声源0～20秒，时间线从0秒开始。
- 删除后第一段：源0～14秒，时间线从0秒开始。
- 删除后第二段：源15.393197～20秒，时间线从14秒开始。
- 原视频总时长约18.606803秒，页面显示00:18.61；原声出现同样裁切，变化已保存。

截图及附件JSON保留实际时间范围；本例没有同时选字幕或原视频，不能将其描述成混合删除部分成功。

**预期结果**

普通Delete应只删除选中的独立音频A1，保留未选中的原视频、原声、字幕及其他配音；原视频/原声继续为完整0～20秒，不能被裁掉A1所占区间或自动缩短。

**影响**

用户删除辅助音频会意外破坏未选中的主视频画面和原声，造成内容缺失、时长缩短及后续时间线变化，影响成片完整性。
