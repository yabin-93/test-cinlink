# 【生产环境】【ERYE210-047】混音后单句配音重新生成报错，目标旧声未替换

云效：[FWXC-579](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=d4687bf3633ef6956037e3a63c)；状态🤔AI提缺陷，负责人牛诗晴，优先级高 / 2-严重。3张原图已上传并嵌入，6个附件及正文回读核验通过（2026-11-16）。

**现象**

在生产环境完成真实英语→中文翻译配音、已有可编辑中文配音的工程中，先将独立WAV背景音量调为50%并保存，再只修改首句配音稿并明确重新生成，页面出现红色错误：“编辑器执行数据不符合正式 v2 协议，请保留当前工程并核对服务返回。”目标新声音未成功替换旧声音，更新流程中断。

**前置步骤**

1. Windows / Google Chrome登录生产环境 https://app.cinlink.ai，账号具备工程编辑权限及足够完成翻译配音前置的积分。
2. 新建专用项目及独立会话，上传附件E196-A.mp4（20秒、1920×1080、30fps、有英语原声），通过“翻译配音”选择“配音和字幕 / 简体中文 / 双语”并完成；进入可编辑源工程，确认至少两句中文稿及对应声音已就绪（本次8句）。普通视频加手工字幕不能替代此前置。
3. 将附件A1-independent.wav（1.393197秒、44.1kHz、单声道）准备为与原声/配音分离的独立背景音频片段，起点14秒、不静音、初始音量100%；保存并记录原片、字幕、各句配音及该背景片段的原状态。

**提示词**

准备工程时，在原生“翻译配音”入口选择上述参数，并发送完整指令：

> 将本次唯一上传的20秒英语原片 E196-A.mp4 翻译成简体中文普通话配音。使用系统默认音色，不使用音色克隆、不做口型同步；保留英语原文与简体中文双语字幕、完整画面、原时长及1920×1080分辨率，保留背景声音且替换原英语人声，不剪辑、不添加水印。请生成可继续编辑的翻译配音工程，目标语言为简体中文，并交付MP4。

目标操作没有新增Agent提示词：只在“配音”页将第1句配音文案修改为“混音后重新生成047。”。本次首句原稿为“通过正式提出申请，企图破坏我们的医疗保障，”；新工程译文若不同，以实际首句为目标，不强行改造其他句子。本次没有补槽。

**复现步骤**

1. 按前置新建并完成真实翻译配音，等待视频及可编辑工程交付；打开视频编辑器，在工程下拉中选择含原片、字幕及分句配音的源工程E196-A.mp4，不选择仅作为成片导入的dubbed-video.mp4。
2. 打开“配音”，确认中文目标文稿及原声音就绪，本次为8句；如需要初始化既有配音展示，在准备阶段完成并等待可用，再开始以下操作，目标执行中不再次创建整批配音。
3. 核对前置的独立WAV片段起点14秒、初始音量100%、不静音，明确区分该轨与原声、原背景和配音轨。
4. 在该WAV片段上实际向下拖动音量线，使页面显示50%；等待页面“已同步”。
5. 刷新页面，重新进入同一工程和“配音”，确认该WAV音量仍为50%、起点仍为14秒，原有配音可见。
6. 只修改第1句配音文案为“混音后重新生成047。”，移开焦点并等待保存；第2～8句保持原稿，不批量生成、不改字幕或原片。
7. 点击第1句旁的“重新生成”图标一次。该步骤为页面明确单句更新，不再发送会话指令。
8. 观察页面及时间线：出现上述红色错误，首句稿处于待更新状态，未完成目标新声替换。保留现场，不连续点击重新生成；核对背景音量及原声音仍保留。

**实际结果**

- 步骤4～5通过：背景音量100%→50%，保存及刷新后保持，起点仍为14秒。
- 步骤7失败：只对第1句明确重新生成后，页面出现完整错误原文“编辑器执行数据不符合正式 v2 协议，请保留当前工程并核对服务返回。”。
- 只读复核时8个原配音文件仍在，未出现已应用的目标新声音；背景音量为0.5、起点14秒，字幕轨保持。不能将后台任务结束等同于页面成功交付新声音。
- 本单仅依据本次真实翻译配音工程的目标操作失败，不采用普通字幕工程、复制上下文或其他准备错误作为失败证据。

**预期结果**

明确重新生成首句后，页面正常展示生成状态并成功将目标旧声音替换为新声音，不遗留同位置叠音；第2～8句稿件和声音不变。已保存的背景音量50%、文件及起点14秒保持，原片、原声和字幕不被串改，刷新后结果仍可编辑、可用。

**影响**

用户在已完成混音的翻译配音工程中无法完成单句改稿后的声音更新，影响后续编辑和交付。
