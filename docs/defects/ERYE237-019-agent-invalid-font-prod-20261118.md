# 【ERYE237-019】Agent非法7字号请求未拒绝，实际文字被钳制为8

云效：[FWXC-679](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=dc51a723d47f6f5dbd5794fcf9)，状态🤔AI提缺陷。已新建，3张原图及2份补充附件已回读核验；[同步报告](ERYE237-019-028-cloud-sync-20261118.md)。

生产https://app.cinlink.ai/，2026-11-18。

**现象**

已设置512源像素后，要求将默认字号改为7并在不支持时明确拒绝、保持原值。Agent仍执行size_px=7；下次请求上下文记录7，页面控件和实际文字探针为8，原512未保持。

**前置步骤**

1. 已登录生产环境，打开有权限的portrait.png图片工程，源图1254×1254。
2. 清空待发引用与正文，通过Agent设置默认字号512并用实际文字探针核验；移除探针。

**提示词**

准备：仅将当前图片编辑器的文字工具默认字号设置为512源像素；不添加文字、不修改、生成或导出图片。保持源图及已完成历史不变。

目标：将当前图片编辑器的文字工具默认字号设置为7源像素。若不在支持范围，请明确拒绝并保持原字号，不自动改成边界值；仅设置，不添加文字、不修改、生成或导出图片。

**复现步骤**

1. 发送准备指令，等待终态并核实实际文字字号为512。
2. 移除自有探针，确认无待发引用，发送目标指令一次。
3. 等终态，核对默认设置；后续513及abc均拒绝且无设置工具调用，再创建独立文字探针读取实际大小。

**实际结果**

目标请求run_v2_b6889faac31244cf88632fc47ee3f540完成，editor_image_view_update实际传size_px=7；下次上下文为7，原生文字工具控件显示8，实际源字号约7.99999，未保留512。源图与完成历史、图片任务集合保持，自有探针已清理。

**预期结果**

非法7应明确拒绝并保留原512，不应写入非法默认值或钳制为8。UI默认样式与其他参数分别记录，不因页面没有自定义字号输入判失败。

**影响**

Agent纯设置未遵守非法值防护，后续新文字及共用工具设置与用户预期不符。
