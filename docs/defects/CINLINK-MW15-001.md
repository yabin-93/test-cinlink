4. 依次上传 A、B，在输入框依次 @ 选择本次两份素材。核对两个引用均存在，第一份为 A，第二份为 B；不能只挂缩略图或只引用一份。


1. 完成上述前置，确认输入区包含 A、B 两个素材引用。
2. 追加完整提示词并发送一次，不拆成两个独立任务。
3. 如果出现补槽，按提示词要求填写并提交，记录问题与答案；如出现计划，核对 A 中文、B 英文、两份视频加两份 SRT 的交付要求后确认。本次未出现上述交互。
4. 等待任务进入终态，记录状态、错误文字、产物清单。
5. 检查是否交付 A 的中文烧录 MP4/中文 SRT、B 的英文烧录 MP4/英文 SRT，并尝试下载。本次在任务失败时没有可下载产物。
