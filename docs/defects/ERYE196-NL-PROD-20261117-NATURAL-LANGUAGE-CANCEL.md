# 【ERYE196-088】自然语言请求发起导出后立即取消，Agent以工具接口限制为由拒绝执行

云效：[FWXC-656](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=4a62ea586c65a5285fc5fde21f)；官方OpenAPI回读核验通过。操作：new。

**现象**

自然语言请求发起导出后立即取消，Agent以工具接口限制为由拒绝执行

**前置步骤**

1. Chrome登录CinLink生产环境，使用获准测试账号U1。
2. 当前会话打开已保存且可播放的E196-A20-controlled.mp4工程：20秒、1280×720，只有视频及关联原声。

**提示词**

对当前已保存的E196-A20-controlled.mp4工程执行一次导出取消测试：先发起一个标识为NL088-CANCEL的MP4导出任务，受理后立即取消这一项，再告诉我它最终是已取消还是已完成。请实际执行发起和取消，不要只回答“不导出了”。如果发起后任务已经完成、无法取消，请明确说明已经完成并保留对应结果。不要取消其他任务，不要重新导出，也不要修改工程。

**复现步骤**

1. 在已打开的保存稿会话中发送完整提示词。
2. 等待同一轮回复，核对是否发起指定导出并取消，或真实完成后明确说明无法再取消。
3. 检查本轮任务、回复及工程保持。

**实际结果**

约63秒结束，Agent明确回复“当前工具无法按要求实际执行这项取消测试”，称导出工具未声明受理即返回任务ID，而取消必须使用真实ID。因此没有发起NL088-CANCEL，也没有实际取消。
会话39c96e1a-63b0-4390-ade8-874444f7e49f；工程1ae1f144-0177-401e-94fd-16c44693546c。

**预期结果**

通过自然语言真实发起并取消本次导出，反馈与实际终态一致；如果真实完成先胜出则明确说明已完成。不能仅以工具描述的限制拒绝整个已支持导出取消业务。

**影响**

用户无法通过自然语言完成导出取消意图。

**补充**

同步标识：ERYE196-NL-PROD-20261117-NATURAL-LANGUAGE-CANCEL
2026-11-17 Chrome生产自然语言实测；本次同步不重跑业务。
报告Agent拒绝执行，不断言后端没有取消接口。另行正常导出NL088-DONE及已完成任务保护均通过，实际20秒MP4有效；未测试账务。
查重：FWXC-645只报原生导出界面缺少取消按钮，本项为自然语言计划拒绝发起；FWXC-654为解说任务积分不足/充值后停止失败，FWXC-236为取消通用Agent后重提无产物，均非同场景。
