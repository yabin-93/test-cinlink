# 【ERYE237-020】选中已有形状后改色只改变工具默认值，未应用于所选对象

状态：已提交[FWXC-508](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=50ee9fa4d3b0829925f48efd27)（2026-11-13），🤔AI提缺陷，牛诗晴，重构10-29，生产环境。3张真实截图及1份审计JSON、正文/附件和业务字段均已回读核验。原生产ego-browser有头主UI分支Failed，固定自动化PLAN未接入。

**现象**

六类形状均可创建、重开及选中，但选中后在颜色面板改色，原形状保持红色；没有找到应用于所选形状的UI入口。

**前置步骤**

1. 生产环境测试账号已登录，打开群鸟JPEG图片工程，原图1000×666。
2. 在干净源版创建红色8px直线、箭头、矩形、圆形、三角形、星形，收起重开。

**提示词**

本例纯UI操作，未发送提示词。

**复现步骤**

1. 点击选择工具，点击已有直线，确认选择框位于该直线。
2. 打开画笔颜色，分别输入R=0、G=0、B=255，关闭颜色面板。
3. 核对实际画布；点击一次撤销，再重做恢复现场。
4. 对其余五种形状分别选中并设不同颜色，逐项取证。

**实际结果**

六次控件分别回读蓝、绿、紫、橙、青、粉，但每次改色前后实际画布RGB严格一致，六形仍红色。撤销均移除最后创建的星形，重做恢复六形画布：尚未建立所选对象的样式修改动作。这里不另立“工具默认色必须可撤销”的要求。

**预期结果**

所选形状具有可用的样式编辑入口；改色实际应用于所选对象并可撤销，其他对象保持。

**影响**

六类形状的创建及选中可用，但无法通过当前页面完成后续颜色编辑，ERYE237-020样式部分未通过。
