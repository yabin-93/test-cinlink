# 【ERYE196-143、ERYE196-144】字幕撤销重做通过重新改文替代，未使用编辑器历史

云效：[FWXC-689](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=1f8e55de30dfe5364e1d759e9d)；官方OpenAPI回读通过。本次新建缺陷。

**现象**

失败请求后的自然语言撤销/重做虽然恢复了字面文字，但实际使用编辑字幕/定点恢复，未执行对应真实历史操作。

**前置步骤**

1. Chrome登录CinLink生产环境，使用获准测试账号U1，打开本例已保存的可编辑工程。
2. 20秒视频及原声保持，已有Welcome 4～6秒、Second caption 10～12秒两条可编辑原文字幕。
3. 每个场景均从独立保存检查点开始；正式成功改文、失败请求、撤销/重做按下述顺序连续执行，中间不刷新或插入其他编辑。

143-P3：

143-P4：

144-P3：

撤销最后一次真正修改工程的操作。

**复现步骤**

143：P1成功改为成功143；P2请求修改不存在目标并被拒绝；P3自然语言撤销最后真实修改，刷新前核对重做控件；P4自然语言重做。

最后各自刷新核对保存文字。
