# FWXC-463 — 纯文字合成后文字由画布腰部移至右上角

[云效缺陷](https://devops.aliyun.com/projex/bug/FWXC-463)；2026-11-13官方API创建及正文/真实截图回读确认。来源：FWXC-369的2026-11-12实测，未新发业务任务。

**现象**

纯文字合成后文字由画布腰部移至右上角

**前置步骤**

生产app.cinlink.ai，Chrome有头，yabinc18。项目9ccba5a7-6b36-4630-9923-15e60a10b0c6；会话https://app.cinlink.ai/c/f8c71e08-b780-4dc9-b7e0-3a146127fd2b 。portrait.png源1254²。文字分支前复位源版并重新导出，尺寸、字节数及SHA256与源一致，未串用画笔结果。文字36px、RGB(255,24,24)，最终为“测试 CinLink 2026”，提交前实际位于腰部。

**提示词**

仅将当前红色笔迹作为最终图片内容合成，保留人像、黄色手包、背景及画幅，不调用AI重绘。

仅将当前文字作为最终图片内容合成，保持准确文字‘测试 CinLink 2026’，不改人像、手包、背景或画幅，不调用AI重绘。

**复现步骤**

1. 独立恢复干净人像源版，进入工具栏文字。
2. 添加文字并通过编辑文字改为“测试 CinLink 2026”，最终36px，确认腰部位置。
3. 携带画笔引用提交原文字完整指令一次，等待完成。
4. 对照提交前草稿与实际成品文字位置，并导出PNG。

**实际结果**

提交前截图显示腰部红字；结果文字内容准确，但移至图片右上角。实际PNG1264²、2579917字节，SHA256 53f4bd97a910d033e24c5b396f90468807cfd72a5b27473d0bf6a398b6cdc1ab，完整解码0。本项报告位置偏移，源尺寸偏差继续留在FWXC-369处理。

**预期结果**

仅将当前文字作为图片内容合成时保持已设定位置、字号及布局，不重新排版到另一位置。

**影响**

文字排版失真，用户无法按画布所见位置交付。
