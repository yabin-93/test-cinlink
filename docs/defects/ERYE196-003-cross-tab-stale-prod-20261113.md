# 【ERYE196-003】视频编辑器跨标签保存字幕后，原标签仍显示旧文且无刷新提示

**现象**

同一工程在B修改字幕保存后，A继续显示旧文，没有提示刷新。关联ERYE196-003，生产Chrome本轮Failed；已提交云效[FWXC-478](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=cf4fd59af9de900c67ec3a9057)。

**前置步骤**

1. 生产环境Chrome登录测试账号，A/B同时打开同一可编辑视频工程。
2. 工程7MB.mp4，约60.50秒；存在143条原文字幕，其中law.唯一位于7.42～7.68秒。

**提示词**

本例直接使用字幕面板编辑，无Agent提示词。

**复现步骤**

1. A读取字幕列表，保持页面打开。
2. B将7.42～7.68秒的law.改为新版C2并保存。
3. 返回A继续浏览字幕列表，查看该字幕、预览及更新提示。
4. 手动刷新A，重开同一工程核对。

**实际结果**

A仍显示law.，未见更新或刷新提示；手动刷新后变为新版C2。全列表143条，仅目标文字变化，其他142条及所有时间保持。会话c247b9a9-a996-4980-a143-5b8321e9ad74。

**预期结果**

A显示已保存的新字幕，或明确提示当前内容已更新、需要刷新；刷新后内容一致。

**影响**

多标签操作时用户可能依据过期字幕继续编辑，无法判断另一标签保存是否已生效。

**补充**

本轮撤销B的修改并刷新A，143条与基线全部一致；保存持久化本身正常，未确认内部根因。历史2026-11-05同编号通过报告保留，本轮生产独立判定。严重程度建议Major。审计003-caption-audit.json及003-restoration-audit.json保存在本批证据目录。
