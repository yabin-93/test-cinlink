# 【生产环境】【ERYE210-002】新视频首次导入编辑器默认进入字幕，未定位Media

云效：[FWXC-482](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=b484370e7d2723d8befafd0441)；2026-11-13通过官方OpenAPI直接新建，不做历史去重。状态🤔AI提缺陷，负责人牛诗晴，生产环境标签，迭代重构10-29，优先级中、严重程度3-一般。

**现象**

新视频首次进入编辑器时，默认选中 Captions/字幕并展示“暂无字幕、生成字幕”，未按新视频场景定位 Media/媒体。

**前置步骤**

1. Windows / Chrome 登录生产环境 https://app.cinlink.ai，账号具有视频工程编辑权限。
2. 新建专用测试项目和独立空会话，尚未创建视频工程或设置工程视图偏好。
3. 准备附件原片 E196-A.mp4：20秒、1920×1080、30fps，含英语讲话及原声。

**提示词**

无 Agent 提示词；本缺陷由页面首次导入视频触发，不发送生成或剪辑任务。

**复现步骤**

1. 在新建空会话点击顶部“视频编辑器”，确认显示“空白工程”。
2. 点击“选择媒体”，选择附件 E196-A.mp4，等待上传及工程创建反馈。
3. 不手动切换任何模块，观察右侧功能栏选中项和内容面板。
4. 核对视频预览及时间线，确认导入的是20秒原片；记录首次入口状态。
5. 本轮额外检查：页面出现创建失败提示后，先回读原工程，再刷新重开；刷新后工程和原片存在，但不据此覆盖首次默认入口结果。

**实际结果**

首次选中“字幕”，显示字幕/样式子页及“暂无字幕、生成字幕”，不是 Media。时间线已有0～20秒视频和关联原声。

同一现场还出现 `Snapshot request could not be completed`，并提示工程创建未完成；保存先返回200/版本1，随后返回500。回读确认工程实际存在，刷新可恢复。该保存异常为伴随观察，本条主要跟踪首次默认入口，不据此推定两者根因相同。

**预期结果**

没有工程视图偏好的新视频首次进入编辑器时，应定位 Media；素材与当前视频工程一致，导航不自动转写或生成。

**影响**

新视频进入字幕空态，用户需要额外手动切换到媒体，首次场景的默认导航与 ERYE-210 要求不一致。
