# 【ERYE196-008】跨工程编辑完成后，结果卡缺少定位到目标工程及字幕的入口

云效：[FWXC-767](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=b62eed2930df8ed174cbd57362)，2026-11-25官方OpenAPI回读核验通过。

**现象**

在工程A发起字幕修改并切换到工程B，任务完成后A已正确修改，页面仍停留在B；完成卡片没有定位到A及目标字幕的入口，展开后只显示编辑步骤说明。

**前置步骤**

1. Chrome登录CinLink生产环境，同一会话内有两个已保存的独立可编辑工程A、B，均由处理任务返回产物后创建。
2. A为ERYE196-A20-30fps-marked.mp4（20秒、30fps），原文字幕为4～6秒Welcome、10～12秒欢迎使用 CinLink；另有两条同时间的译文Welcome、原声和独立BGM。B为ERYE196-B10-30fps-blue.mp4（10秒），只有视频和原声；记录两工程基线。

**提示词**

只把工程A这条字幕原文改为A目标固定。工程A指当前打开的ERYE196-A20-30fps-marked.mp4，目标为4～6秒原文Welcome，其他内容不变。

**复现步骤**

1. 在工程A定位4～6秒原文Welcome，发送上述提示词。
2. 请求已开始且尚未完成时，通过同页工程选择器切换到B，等待原任务完成。
3. 检查完成卡片及其展开内容，尝试从卡片定位到工程A及本次修改的字幕。
4. 手动切回A并刷新核对修改，比较B与原基线。

**实际结果**

任务28秒显示“已完成”，标题为“修改工程 A 的指定原文字幕”。卡片及展开内容只有“编辑字幕”和“编辑字幕完成后将自动开始下一步。”，未提供定位到目标工程及字幕的操作。

A的4～6秒原文已变为“A目标固定”，刷新后保持；同时间译文和其他字幕保持。B视频及原声仍为0～10秒，内容未被修改，任务结束时页面仍显示B。工程隔离与不抢占视图通过，失败范围仅为结果卡定位入口缺失。

会话：https://app.cinlink.ai/c/7438a430-91a2-4219-a100-e6e7d85d7a65

**预期结果**

结果卡提供目标定位入口。用户主动点击后切换到发起工程A，并定位本次修改的4～6秒字幕；后台完成时仍保持B视图。

**影响**

用户在其他工程等待任务完成后，无法从结果卡直接回到修改位置，只能手动查找工程和字幕，增加核对成本。
