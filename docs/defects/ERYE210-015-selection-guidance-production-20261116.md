# 【生产环境】【ERYE210-015】未选片段时分割按钮禁用，但缺少先选择片段的原因提示

云效：[FWXC-586](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=d5da04deb674cf55972715cfb1)；官方OpenAPI新建，状态🤔AI提缺陷，负责人牛诗晴，低 / 4-轻微。3张本轮原图上传并嵌入，6附件及正文/字段/图片引用回读通过。

**现象**

Scripts（文稿）页的时间线没有选中片段时，“分割所选片段”按钮正确禁用，但悬停或页面说明只有操作名，没有“请先选择片段”或等价前置原因提示。选择视频后分割、撤销均正常；本缺陷不报告分割失败。

**前置步骤**

1. Windows / Google Chrome登录生产环境 https://app.cinlink.ai，账号具有工程编辑权限。
2. 新建专用项目、独立会话及可写工程，准备附件20秒原片、关联原声和8条英语字幕，保存完成且原视频仍为一段。
3. 工程无运行任务，进入Scripts后保持没有片段选中；不发起口水词分析，也不准备文字选区。

**提示词**

无Agent提示词；只在页面选择片段、调整播放头、分割和撤销，无补槽、无生成任务和run。

**复现步骤**

1. 为独立回归导入附件E196-A.mp4，再导入E196-A-en.srt并绑定为原文英语字幕，确认20秒视频、关联原声及8条字幕已保存。本轮实际通过新工程加载真实素材/字幕基线准备，未复用已分割的旧工程。
2. 点击Scripts/文稿，等待页面就绪。按Esc或点击时间线空白取消片段选择，确认没有片段选中边框。
3. 查看时间线工具栏“分割所选片段”按钮：按钮为禁用态。将鼠标悬停，检查按钮提示及附近说明；保存截图一。
4. 实际只有“分割所选片段”名称，未说明“请先选择片段”或等价恢复条件；未误将整片作为操作目标。
5. 作为对照，单击唯一原视频片段，再用原生播放进度条将播放头定位约12秒，确认按钮恢复可用。本轮显示12.03秒，30fps时间线实际分割点12.033333秒。
6. 点击一次“分割所选片段”，等待已同步：同一原视频分为0～12.033333秒及12.033333～20秒，两段连续，总长仍20秒；保存截图二。
7. 点击一次撤销，核对恢复原始单片段及原媒体引用，原片、原声及字幕内容恢复；保存截图三。

**实际结果**

无选区时按钮禁用，实际读到的提示仅为“分割所选片段”，没有选择片段的原因说明。选中后按钮恢复；约12秒实际分割成功，总长保持20秒，一次撤销恢复原结果。

**预期结果**

缺少片段选区时，按钮保持不可用，同时通过悬停提示或就近说明明确告知“请先选择片段”或等价操作前提。选中有效片段后恢复可用，不猜测整片为目标。

**影响**

用户无法从灰色按钮判断缺少片段选择，容易与权限不足或功能不可用混淆，需要自行摸索恢复条件。本轮没有数据损坏或分割/撤销异常。
