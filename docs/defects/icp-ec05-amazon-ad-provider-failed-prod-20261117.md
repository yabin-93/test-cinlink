# 【生产环境】【电商Case05】根据吸尘器图片制作20秒广告时供应商视频处理失败，未交付成片

云效：[FWXC-631](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=fc2731f00849917dfea1868f89)；🤔AI提缺陷，牛诗晴，生产环境。1张失败原图已上传并嵌入，5份附件及正文回读通过。本次只同步2026-11-16既有实测，未重跑产品。

**现象**

仅用吸尘器真实商品图片制作20秒Amazon广告，图片排序完成后视频生成报供应商处理失败，后续尺寸调整未执行，完整广告未交付。

**前置步骤**

1. Windows / Ego Lite登录生产环境，新建专用项目和独立会话。
2. 准备BLACK+DECKER HHVK515JP07的5张真实商品图（侧面、总览、吸头、集尘盒、手持展示）、Logo及已确认事实表。
3. 无现成视频、无背面/底部图片；不得补未知结构或编造吸力、续航数据。

**提示词**

第1轮原文（电商场景!B65，整段一次发送）：

```text
我是一名 Amazon 美国站的手持吸尘器卖家，现在只有几张商品图片和产品介绍，没有拍摄好的产品视频。

我希望你根据现有素材，帮我制作一条 20 秒、16:9 的产品广告视频。

具体要求：
先查看上传的商品图片和产品介绍，了解产品的真实外观、配件和主要功能。
视频开头展示产品整体外观，可以让静态图片中的产品产生自然的镜头运动，让用户看清产品。
根据现有图片，尝试用 AI 生成模特（或手部模特）手持产品在桌面清洁碎屑、手持使用等场景。如果素材无法确认实际使用方式，请先告诉我，不要随意生成不符合产品真实功能的画面。
中间重点展示产品吸头、集尘盒等已经提供素材的部分，让用户了解产品的特点。
添加简短的英语卖点文字，最后展示品牌 Logo。
整体风格简洁、真实，适合 Amazon 商品广告。即使没有声音，用户也能看懂视频内容。
生成画面中的产品外观、颜色、按钮、吸头和配件必须与真实商品一致，不要添加不存在的结构。
不要编造吸力数据、续航时间或其他未经证实的产品效果。
请尽量使用现有图片生成需要的动态画面，并完成整条广告。如果某些镜头无法准确生成，请告诉我原因，并尝试其他不改变真实产品的展示方式。
```

**复现步骤**

1. 在新会话一次附上5张商品图、PNG Logo和纯事实TXT共7份素材。
2. 一次发送第1轮完整原文，要求20秒、16:9、英语卖点、Logo收尾，素材不足可用不改变产品的替代展示。
3. 沿原任务等待图片排序及视频生成；本次没有制作补槽，不重复发送、不点击重试。
4. 检查视频生成错误、后续尺寸调整状态及最终20秒成片是否交付。

**实际结果**

任务failed，图片排序完成，“生成视频”节点报Tencent VOD video processing failed at the provider.；后续裁剪/尺寸调整未执行，无20秒广告MP4交付。

**预期结果**

基于可确认素材完成广告；无法准确生成某镜头时如实说明并尝试允许的真实产品替代展示，避免整条广告停留在供应商失败。

**影响**

无现成视频的商品广告制作被阻断，依赖首稿的外观、动作和卖点修改不能执行。
