# 【ERYE196-081】ProRes源导入后重开编辑器出现页面错误，云端代理未恢复工程预览

云效：[FWXC-641](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=e6aef0651f14e63124a846527d)，官方OpenAPI回读核验通过。

**现象**

ProRes导入后重开编辑器出现页面错误；云端同源代理可生成播放，未回填工程。

**前置步骤**

1. Chrome登录生产环境，同一测试项目中新建独立会话。
2. 源E196-prores-4s-081.mov：4秒、1280×720、ProRes MOV、约26.86MB，原文件已登记。

**提示词**

素材登记指令（完整原文）：

ERYE196-081素材登记：仅登记本条附件E196-prores-4s-081.mov，4秒1280×720的ProRes MOV原始测试源，不转码、不生成、不剪辑、不导出。稍后我会在当前独立会话通过视频编辑器打开原源并验证浏览器播放与云端预览。保留原始文件。

编辑器出错后，独立云端编码支持核验指令（完整原文）：

继续执行ERYE196-081：本会话原始文件E196-prores-4s-081.mov（file_cloud_5zpuh3t3eknegcuyvf6jg4gjgz）为4秒1280×720 ProRes。Chrome原生不能解码视频帧；刚才通过视频编辑器选择该MOV后，再打开编辑器出现“页面暂时无法显示”，现已重新加载恢复会话。请只用同一原始MOV进行云端编码支持核验：探测原源并生成一个4秒1280×720 H.264/AAC MP4，作为可播放代理和导出对照，交付实际文件。不生成新内容、不截短、不改变尺寸或画面，不覆盖原源、不把代理静默替换为原始文件，不修改本项目其他工程。若能回填当前工程的代理预览，请明确说明并保留源引用；若不能，请如实说明。

**复现步骤**

1. 登记原始MOV；点击原附件播放入口，核对是否实际解码出视频帧。
2. 打开视频编辑器，在空白工程“选择媒体”中选择同一MOV。
3. 再次打开视频编辑器，检查页面状态；出错后使用重新加载恢复会话。
4. 发送上述独立云端核验指令，仅处理同一MOV；下载并在Chrome显式播放实际代理。

**实际结果**

原附件显式播放时视频宽高0、解码帧0；选择MOV后再开编辑器显示“页面暂时无法显示/重新加载”。云端同源核验93秒完成，交付4秒1280×720 H.264/AAC MP4，完整解码120帧，Chrome实际播放正常（16帧以上）。回复明确“当前工程的代理预览未回填”。原源仍保持同一标识、文件名及26,861,020字节，不是把代理当原源交付。
会话0ef56036-b599-469e-9341-1b2a1526178f。

**预期结果**

云端可处理而浏览器不能解码的原源，应明确提供代理/云端预览降级，保留原文件并允许继续编辑，不能进入页面错误而无法恢复工程预览。

**影响**

该类可由云端转码的源无法继续在视频编辑器正常查看或编辑，只得到会话中的独立代理文件。
