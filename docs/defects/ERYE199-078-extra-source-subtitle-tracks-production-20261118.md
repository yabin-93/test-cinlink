# 同会话从原文字幕切换至译文、双语译配后多出前轮英文字幕轨

关联用例：ERYE199-078；生产环境，2026-11-18，Ego Lite 0.6.3.14。已同步云效[FWXC-694](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=c6fcf26c6c51304682eec70a9b)，对应4张截图已上传并嵌入，6附件回读通过。

前置：

1. 登录生产环境，新建本批测试项目及独立会话，账号积分充足。
2. 准备20秒英语原片 `F20-English-source-with-BGM.mp4`（1280×720/30fps，原片无字幕、画面带源时钟和低音量背景乐）。
3. 三轮均显式重新附加同一原片；不选择前轮成片，不使用@引用。

完整提示词按顺序为：

1. `为这条视频添加原文字幕。`
2. `为这条视频添加简体中文字幕。`
3. `将这条视频翻译成简体中文配音，并显示中英双语字幕。`

复现步骤：

1. 首页选择“添加字幕”，参数为不翻译、原文；上传F20，一次发送第1条提示词并等待完成。从本轮结果进入编辑器，核对英文字幕三轨。
2. 返回同一会话，通过输入框“/”选择添加字幕，设置简体中文、译文；重新附加F20，一次发送第2条提示词并等待完成。
3. 从第2轮结果进入编辑器，展开所有轨道，在2秒和10秒处查看字幕预览。
4. 仍在同一会话，通过“/”选择翻译配音，参数为配音和字幕、简体中文、双语；重新附加F20，一次发送第3条提示词并等待完成。
5. 从第3轮结果进入编辑器，核对全部轨道及中英预览。
6. 依次重新打开三个历史结果，复查各自轨道和源片。三轮本次均未出现补槽，没有重发已受理任务。

实际：第1轮为原文字幕、视频、原声3轨；第2轮为2条“译文字幕”、视频、原声4轨，第一条中文、第二条英文，选择译文时仍同时显示中英；第3轮为2条“译文字幕”、视频、原声、配音、背景音乐6轨。多出的英文字幕源与第1轮原文字幕相同。视频本身三轮均来自F20，三个独立工程的历史结果没有被后轮覆盖。

预期：三轮分别维持原文字幕三轨、译文字幕三轨、双语译配五轨。第2轮预览只显示中文；第3轮中英在同一条译文字幕模式中对应显示，不因沿用前轮英文字幕而额外增加一条原文内容轨。
