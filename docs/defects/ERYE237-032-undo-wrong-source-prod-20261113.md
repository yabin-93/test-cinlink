**现象**

本地编辑批次一次撤销后切到其他保存版，未恢复编辑前源图

**前置步骤**

1. 生产环境 https://app.cinlink.ai/，测试账号yabinc18已登录，ego-browser有头。
2. portrait.png工程有两个可区分的1024×1024保存版：选中A的红色“T1 新品”；另有B的蓝色“T1 新品”和“保留内容”。

**提示词**

```text
在当前图归一化(0.1,0.1)添加白色48源像素可编辑文字“新品”，再将同一文字移到(0.7,0.1)，加红色8源像素箭头从(0.7,0.2)指向(0.25,0.25)。仅本地编辑并确定性合成，保留原尺寸，不要AI生成。整组作为一次撤销单元。
```

**复现步骤**

1. 先在历史中查看A（红字），确认无其他草稿和待引用项。
2. 通过普通Agent发送下方完整三步本地批次指令一次。
3. 执行完成后核对只有一份可选文字与箭头，再点击一次UI撤销。
4. 比对撤销后的实际画布与A以及B的RGB数据。
