# 【ERYE196-087】编辑器实际导出处理中没有取消该导出的操作入口

云效：[FWXC-645](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=a59bce2867980857a09db9f76e)，官方OpenAPI回读核验通过。

**现象**

实际导出处理期间没有取消入口；排队取消分支未覆盖。

**前置步骤**

1. macOS Chrome登录CinLink生产环境，测试账号U1（yabinc92）。
2. 打开独立20秒视频工程E196-A20-controlled.mp4（1280×720），原视频及关联原声已保存。

**提示词**

无Agent提示词，通过视频编辑器右上角“导出”按钮。

**复现步骤**

1. 点击“导出”一次。
2. 在按钮显示“正在导出…”时检查工具栏及当前导出相关界面。
3. 查找针对该实际导出的取消操作，区别于无关Agent任务的停止按钮。

**实际结果**

在真实导出处理期间，右上角为禁用的“正在导出…”状态，没有取消该导出的操作。工具栏、当前会话导出相关界面及账户入口均未提供该操作。原30秒工程和独立20秒工程均观察到同一现象。
20秒工程会话520159ef-7b0a-4b0e-8ff8-979eb945b431。

**预期结果**

已受理且正在处理的导出提供明确取消入口与处理结果；取消行为作用于该导出任务。

**影响**

用户发起错误或不再需要的导出后，无法通过当前界面主动取消。
