# 【ERYE196-086】工作台及账户菜单缺少任务中心和按工程筛选任务的入口

云效：[FWXC-644](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=a23cbf73e71ea5b7efb1954859)，官方OpenAPI回读核验通过。

**现象**

账户菜单及工程界面未提供任务中心和按工程过滤的任务列表入口。

**前置步骤**

1. Chrome登录CinLink生产环境，测试账号已有视频编辑工程和实际导出历史。
2. 保留同一项目中多个会话的已完成任务，便于核对任务汇总与工程筛选入口。

**提示词**

无Agent提示词，检查工作台、项目/会话界面及账户菜单。

**复现步骤**

1. 从已有会话和项目页面查找账户级任务列表入口。
2. 打开左下角账户菜单，查看可用功能。
3. 检查是否能进入任务中心并按工程筛选导出/生成任务。

**实际结果**

账户菜单仅见升级、积分、语言、设置、联系我们、退出登录，项目/会话只有各自执行卡与产物；未提供账户级任务中心或工程任务筛选入口。同步前在同一Chrome生产会话只读复核，菜单仍为上述选项，已补齐对应截图。
本次复核会话520159ef-7b0a-4b0e-8ff8-979eb945b431。

**预期结果**

按需求提供可见任务中心入口，支持查看账户任务并按工程筛选，便于恢复和追踪导出/生成任务。

**影响**

用户必须逐个会话翻找任务，无法通过任务中心汇总和按工程筛选。
