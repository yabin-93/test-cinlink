# 【生产环境】【电商Case03】TikTok成片结尾只有品牌标识，未添加要求的Shop Now CTA

**现象**

原文要求TikTok版本结尾添加CTA，已提供Shop Now事实资料，实际成片的结尾只有品牌标识，没有CTA文字。

**前置步骤**

1. Windows / Ego Lite登录生产环境，新建测试项目和独立会话。
2. 上传本次300秒、1280×720英语产品介绍视频、ADO产品事实表和Logo；事实表明确CTA为Shop Now。
3. 使用第1轮原文同时制作三版，B为15～20秒、9:16的TikTok独立工程。

**提示词**

第1轮原文（电商场景!B35，整段一次发送）：

```text
我是一名品牌社媒运营，现在有一条已经制作好的 5分钟的横版产品视频，希望你帮我改成适合不同平台的三个版本：
A：Instagram Reels 版本
调整成 9:16 竖屏，时长控制在 20–30 秒。
保留原视频中最好的产品展示镜头和主要卖点。
保持品牌原有的画面风格，整体看起来简洁、精致。
调整字幕和产品位置，确保竖屏下都能完整看到。

B：TikTok 版本
调整成 9:16 竖屏，时长控制在 15–20 秒。
开头 2–3 秒直接展示产品最吸引人的功能或使用效果。
适当加快剪辑节奏，删掉不重要的内容。
添加清晰的英语字幕和结尾 CTA。

C：Shopify 商品详情页版本

保留 16:9 横屏，时长控制在 25–30 秒。
重点展示产品外观、主要功能和实际使用过程。
保留必要的产品介绍和品牌信息。
即使静音播放，也能通过画面和文字看懂产品的主要特点。

其他要求：
请优先使用原视频中的真实画面，不要随意改变产品外观和功能。
横屏转竖屏时，尽量保证产品主体完整，不要把产品的重要部分裁掉。
如果原画面不适合直接裁成竖屏，可以尝试用 AI 补充缺失的背景，让画面看起来自然，但不要改变产品本身。
三个版本分别制作，保留各自适合的平台风格，并支持后续单独修改和导出。
```

**复现步骤**

1. 上传素材后一次发送第1轮原文；出现方案审核时原样确认，不手动添加CTA。
2. 等三版完成并下载实际B-TikTok.mp4。
3. 播放B成片的结尾品牌段（约16.5秒至19.3秒，截图为17.36秒），查看是否存在CTA，不能把Logo文字当CTA。
4. 对照商品事实表已给出的Shop Now及B工程文字对象/成片，记录结尾实际内容。

**实际结果**

B成片19.300秒、1080×1920。结尾展示ADO品牌标识，未见Shop Now或其他明确行动引导文字；实际文件及工程核验一致。

**预期结果**

B结尾保留品牌信息并添加明确的CTA；已有Shop Now资料时使用该文案，不应仅交付Logo收尾。

**影响**

TikTok广告缺少明确购买/访问引导，不满足该版本的明确交付要求。
