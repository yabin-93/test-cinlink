# 【生产环境】【电商Case03】连续修改TikTok时工程或素材引用冲突，15秒改版和安全区修正版未交付

云效：[FWXC-629](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=8014ebc4b36863fc090d9a5ad8)；🤔AI提缺陷，牛诗晴，生产环境。3张失败原图已上传并嵌入，7份附件及正文回读通过。本次只同步2026-11-16既有实测，未重跑产品。

**现象**

对已交付TikTok进行15秒改版时，高光工程报工程/修订不匹配；再基于最近有效TikTok改安全区时，Editor batch apply报原文件引用冲突。两条修订均未交付。

**前置步骤**

1. Windows / Ego Lite登录生产环境，新建专用项目和独立会话。
2. 上传同一300秒横版产品视频、事实表和Logo，用原文先制作三版独立成片；初稿B约19.3秒。
3. 后续在本例会话连续修改，不能用失败的新B15草稿冒充有效B版本。

**提示词**

第1轮原文（电商场景!B35，整段一次发送）：

```text
我是一名品牌社媒运营，现在有一条已经制作好的 5分钟的横版产品视频，希望你帮我改成适合不同平台的三个版本：
A：Instagram Reels 版本
调整成 9:16 竖屏，时长控制在 20–30 秒。
保留原视频中最好的产品展示镜头和主要卖点。
保持品牌原有的画面风格，整体看起来简洁、精致。
调整字幕和产品位置，确保竖屏下都能完整看到。

B：TikTok 版本
调整成 9:16 竖屏，时长控制在 15–20 秒。
开头 2–3 秒直接展示产品最吸引人的功能或使用效果。
适当加快剪辑节奏，删掉不重要的内容。
添加清晰的英语字幕和结尾 CTA。

C：Shopify 商品详情页版本

保留 16:9 横屏，时长控制在 25–30 秒。
重点展示产品外观、主要功能和实际使用过程。
保留必要的产品介绍和品牌信息。
即使静音播放，也能通过画面和文字看懂产品的主要特点。

其他要求：
请优先使用原视频中的真实画面，不要随意改变产品外观和功能。
横屏转竖屏时，尽量保证产品主体完整，不要把产品的重要部分裁掉。
如果原画面不适合直接裁成竖屏，可以尝试用 AI 补充缺失的背景，让画面看起来自然，但不要改变产品本身。
三个版本分别制作，保留各自适合的平台风格，并支持后续单独修改和导出。
```


```text

请分别调整这两个版本的字幕和产品位置，让重要内容完整显示在画面中间的安全区域。不要改变视频原本的内容和剪辑顺序，Shopify 版本保持不变。
```

**复现步骤**

1. 顺序发送第1～3轮原文，每轮终态后再进入下一轮；第1轮审核原样确认，第2轮为Reels局部修复。
2. 第3轮AI补背景错误是假设，本次实际未使用AI背景；补槽如实填写附件中的原回答，保留现有真实视频，不制造错误。
3. 一次发送第4轮原文要求TikTok约15秒、前3秒突出使用效果，等待“选择精彩片段→生成高光工程”。
4. 记录生成高光工程的工程/修订不匹配错误，没有15秒成片；不点击重试。
5. 从工程选择器切回最近有效的约19.3秒B/TikTok（不是5分钟失败B15草稿），A用第2轮修正版，C保留首稿。
6. 发送第5轮安全区原文，等待A/B修改和导出；检查A交付、B节点错误与C是否保持。

**实际结果**

第4轮failed：“The saved highlight belongs to a different project or revision”，无15秒改版。第5轮整体done但B的Editor batch apply失败：“REFERENCE_CONFLICT / Snapshot original file references do not match”；只交付A安全区修正版，B仍为19.3秒旧版，C保持。

**预期结果**

应用应在当前选定的有效独立工程及正确素材引用上完成TikTok15秒改版和安全区调整，交付对应新视频，A/C按指令保持。整体done不能替代B交付。

**影响**
