# 【生产环境】【ERYE210-018】配音期间保存独立水印后，原配音任务提示没有可应用结果

云效：[FWXC-506](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=df279e880064725c26669adc36)；2026-11-13通过官方OpenAPI直接新建，不做历史去重。状态🤔AI提缺陷，负责人牛诗晴，重构10-29，生产环境，优先级高、严重程度2-严重。

前置各三条，详细复现及验证边界单列。3张真实截图已上传并嵌入，连同原片、供回归准备的中文SRT及核验JSON共6附件；正文、字段、附件ID/名称/字节数及图片引用回读通过。用例ERYE210-018保持Failed。[本轮执行报告](../cases/requirements/ERYE-210/results-016-020-prod-20261113.md#erye210-018)。

**现象**

创建两句配音期间，页面允许保存独立文字水印；随后原配音任务提示“当前任务没有可应用结果。”，未形成两句配音。独立水印仍保留。

**前置步骤**

1. Windows / Google Chrome登录生产环境https://app.cinlink.ai，账号具备视频工程编辑及配音生成权限。
2. 新建专用测试项目及独立会话/工程，准备附件20秒原片和两句中文待配音稿：4～6秒“欢迎使用 CinLink。”、10～12秒“这是导航测试。”。
3. 确认该工程尚无旧配音和水印、无其他任务，准备完成并已保存。

**提示词**

无Agent提示词；通过页面点击创建配音、编辑水印，无补槽。

完整待配音文稿及时间为：
`00:00:04,000 → 00:00:06,000 欢迎使用 CinLink。`
`00:00:10,000 → 00:00:12,000 这是导航测试。`
水印完整输入值：`INDEPENDENT_018`。

**复现步骤**

1. 在本轮新建的独立工程中进入Voiceover/配音，核对待配音文稿，并确认还没有旧配音音频。
2. 点击一次“创建配音”；观察按钮进入禁用状态，等待期间不要重复点击。
3. 在配音尚未完成时切换Watermark/水印，选择“文字”，在文字框输入`INDEPENDENT_018`，点击框外完成保存；本次该输入框可用。
4. 保持同一工程，依次浏览Media、Scripts、Captions、Voiceover、Watermark，确认入口仍可切换。
5. 返回Voiceover，等待原任务结果；本次显示红色提示“当前任务没有可应用结果。”。
6. 继续核验原任务约3分钟：仍没有两句可用配音；检查独立水印仍显示`INDEPENDENT_018`。不要重新提交生成覆盖本次现场。

**实际结果**

只观察到一次真实配音提交，目标为本工程；配音尚无ready音频时，独立水印已保存，五入口可浏览。原配音任务随后提示“当前任务没有可应用结果。”，等待后配音仍为0句。

最终保存核验为版本3、配音数组为空，文字水印为`INDEPENDENT_018`；没有发生水印丢失。本条报告配音没有形成可应用结果，不声称已经证明错误由水印修改导致。

**预期结果**

页面允许的独立水印编辑应正确保存，原配音任务也应形成与两句文稿对应的可用音频；允许的独立编辑不应使任务留下不可应用结果。如当前处理中存在业务限制，应在操作前明确提示或限制操作，不能先允许后仅报无法应用。

**影响**

用户在等待配音时继续页面允许的编辑，最终无法获得配音结果，需要重新处理；结果失败提示缺少可操作的恢复说明。
