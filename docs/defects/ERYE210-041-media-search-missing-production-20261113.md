# 【生产环境】【ERYE210-041】Media聊天/工程空素材区域缺少素材名称搜索入口

云效：[FWXC-518](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=775dbf83cad7c40e3d8432d74e)；状态🤔AI提缺陷，负责人牛诗晴，生产环境。正文、字段及3个附件回读核验通过。

**现象**

进入Media（媒体）的“聊天”和“工程”素材页，加载完成后均未提供可见素材名称搜索入口，无法继续ERYE210-041中的按素材名称搜索与清空搜索操作。

**前置步骤**

1. Windows / Google Chrome登录生产环境 https://app.cinlink.ai，账号具备视频工程编辑权限。
2. 新建专用项目、独立会话和可写视频工程，工程内已有20秒视频及英语字幕，右侧五个功能入口可用。
3. 使用当前新会话/新项目的Media素材区域；本轮聊天和工程素材列表为空，页面加载已结束。

**提示词**

本次为编辑器页面导航和控件检查，无Agent提示词、补槽或生成run；未提交素材添加或生成任务。

**复现步骤**

1. 打开新工程，点击右侧“媒体”（Media）。
2. 点击素材面板顶部“聊天”（Chat），等待“加载中”提示消失，查看素材区域顶部及列表。
3. 查找可按素材名称输入的搜索框或可打开搜索框的按钮，记录聊天页现场。
4. 点击“工程”（Project），等待加载结束，按同样方式查找素材搜索入口并记录现场。
5. 尝试进入用例要求的按名称搜索、清空搜索步骤；当前无可操作入口，后续搜索步骤停止。
6. 确认浏览两页未向时间线添加素材、未切换目标工程、未生成新任务。

**实际结果**

- 聊天和工程页都能切换并结束加载。
- 面板仅显示聊天/工程切换及导入素材入口；本轮空素材区域没有可见搜索框或搜索按钮。
- 无法执行素材名称搜索及清空搜索；时间线、目标工程和生成任务保持未变。

**预期结果**

按ERYE210-041及其所追踪设计，Media在聊天/工程素材范围内提供明确可操作的素材名称搜索入口，支持输入并清空搜索；筛选不自动添加素材或触发生成。若空列表计划隐藏搜索，应明确该适用条件并同步验收口径。

**影响**

当前页面不能完成用例要求的素材搜索入口验收，用户无法从本轮页面开始按名称查找素材。
