# FWXC-461 — 图片生成中点击可用的已完成历史版本仍只显示处理占位

[云效缺陷](https://devops.aliyun.com/projex/bug/FWXC-461)；2026-11-13官方API创建及正文/真实截图回读确认。来源：FWXC-373的2026-11-12实测，未新发业务任务。

**现象**

图片生成中点击可用的已完成历史版本仍只显示处理占位

**前置步骤**

生产app.cinlink.ai，Chrome有头，yabinc92 Creator。项目d15de3bc-fa92-431b-8e8f-dbed3d151a22；会话https://app.cinlink.ai/c/b005f0d4-e427-4270-9a7c-ef1142302ae4 。授权portrait.png为1254×1254红衣人像、黄色手包。素材登记后导入并去背景一次，再恢复带背景原版；原/去背景两个完成历史就绪。擦除笔刷主体20px、提手8px，非空mask及自动擦除引用已核实。

**提示词**

移除涂抹区域内的黄色手包，用周围一致的背景自然补齐该区域；保留人物的脸、头发、手、手臂、红色上衣、牛仔裤、白鞋及人物阴影，不新增其他物体，画幅不变。

**复现步骤**

1. 使用擦除工具涂抹手包，核对非空mask和擦除引用。
2. 发送完整目标指令一次。
3. 实际生成运行中点击已完成原始版历史。
4. 在任务完成前核对画布是否显示原图，终态后对照原图是否可显示。

**实际结果**

17:56:37发送，17:56:49仍正在生成图片；已完成历史按钮不再disabled。17:56:55实际点击原始版，画布仍显示正在生成/正在处理图片占位，未显示原图。17:57:05任务完成，17:57:20三个历史出现，17:57:20后原版可显示。另一历史点击已在终态，不计运行期第二次验证。

**预期结果**

点击已完成历史后实际显示对应图片；处理中内容编辑限制不应遮挡已有成果查看。

**影响**

虽然按钮已可点，用户等待生成时仍无法查看或对比已完成版本。

**补充**

同步标识：REG-R2-HISTORY-PLACEHOLDER-20261113

发现于2026-11-12生产回归，2026-11-13按用户要求与原缺陷FWXC-373区分登记。原FWXC-373“全部历史入口disabled”已不复现；本项是点击后画布显示偏差，运行期只有一次有效取样。 本次仅同步已有实际执行证据，没有重发任务；run_id未可靠取得，不编造。已分页查重并回读相关原缺陷，未发现相同触发条件与现象的既有项。
