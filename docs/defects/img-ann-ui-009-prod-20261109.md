**复现步骤**

1. 打开上述会话的图片编辑器，选择带背景的源版本。
2. 在人物右下侧空白地面建立批注1，在浮层填写完整正文，自定义对象名称为“右侧空白地面”。不添加到对话、不发送。
3. 等待页面显示“已保存”。
4. 点击“收起图片编辑器”离开，再点击页面“视频编辑器”入口重开同一人像工程。
5. 点击仍存在的批注1，核对正文、对象名称和添加按钮状态。
6. 为排除输入驱动影响，通过实际点击、粘贴重新填写正文和对象名，再次等待已保存，重复收起及重开，仍出现同样丢失。

批注点保留，正文变为空输入框，自定义名称消失；重新识别后对象显示“物体”，“添加到待引用项”（画面“添加到对话”）禁用。两次关闭/重开均观察到该现象；实际粘贴输入复核仍复现。同会话、同名画布、两项版本历史保持，没有刷新或重传替换工程。未提交生成任务，无正式生成run_id。

**预期结果**

页面提示“已保存”后，正常收起并重开同一工程，应恢复未发送批注的位置、完整正文及自定义对象名，用户可继续编辑或添加到对话，无需重复填写。

**影响**

用户离开编辑器后丢失已填写的批注指令及对象命名，需重新输入，影响草稿保存可靠性及后续编辑。
