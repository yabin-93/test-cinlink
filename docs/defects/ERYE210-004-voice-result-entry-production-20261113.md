# 【生产环境】【ERYE210-004】配音生成后缺少从结果直接定位Voiceover编辑的入口

云效：[FWXC-483](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=bc663b74e4bf60d0019f5c04e3)；2026-11-13通过官方OpenAPI直接新建，不做历史去重。状态🤔AI提缺陷，负责人牛诗晴，生产环境标签，迭代重构10-29，优先级中、严重程度3-一般。

前置步骤按用户要求精简为三条；完整提示词和复现步骤保留。3张原始截图已上传并在云效正文嵌入，共8个附件；原图SHA-256本地核验，云效正文、字段、附件ID/名称/字节数及图片引用回读通过。

用例ERYE210-004保持Failed，本次仅同步缺陷，没有重跑业务或修改其他工作项。[本地执行报告](../cases/requirements/ERYE-210/results-001-005-prod-20261113.md#erye210-004)。

**现象**

工程已有成功生成的配音及对应文稿，当前页面仍缺少可从配音结果直接定位 Voiceover/配音编辑的明确入口；用户需要自行切换配音模块查找文稿。

**前置步骤**

1. Windows / Chrome 登录生产环境 https://app.cinlink.ai，账号具有视频工程编辑及配音生成权限。
2. 新建独立视频工程，准备附件20秒原片，以及4～6秒、10～12秒两条受控英文/中文SRT。
3. 在配音页成功生成两句中文配音并保存，将当前模块设为 Media。

**提示词**

本条导航复现无 Agent 目标提示词；通过页面“创建配音”准备结果，不重复生成或使用失败任务充当合法结果。

受控配音文稿分别为：4～6秒“欢迎使用 CinLink。”；10～12秒“这是导航测试。”。这是导航测试短句，不作为原片讲话的完整翻译。

**复现步骤**

1. 在本轮独立视频工程导入附件原片，完整放置于0～20秒，保留关联原声。
2. 分别将附件 `004-controlled-source.srt`、`004-controlled-translation-utf8.srt` 绑定为英文原文和中文译文字幕，核对文字、时间和语言；本轮通过附件 `controlled-fixture-template.json` 准备：先上传三份素材，以本环境实际素材ID替换模板占位，并填写新会话、新工程及新操作标识，按模板保存一次，再在工程选择器中选中新工程。该模板仅准备素材和字幕，配音仍须在下一步真实生成。
3. 明确选择该独立工程，进入 Voiceover/配音，点击“创建配音”一次，等待两句真实生成及保存；确认中文文稿正确、两段配音已进入时间线。
4. 切换 Media，收起编辑器，再从会话顶部“视频编辑器”重新打开同一工程。
5. 查看是否存在可从已生成配音结果明确定位配音文稿的编辑入口；本轮未找到该入口。
6. 核对现有结果交互：单击第一段已生成配音片段；再点击 Media 中对应的 WAV 文件。记录当前模块和显示内容，不把普通素材预览当作编辑入口。
7. 手动切换 Voiceover 仅核对工程和文稿仍正确；回读保存内容，确认上述导航未修改或重新生成配音。

**实际结果**

两句中文配音真实生成成功，状态均为ready，开始于4秒和10秒，音频时长约1.347秒、1.393秒。首句实际预览播放完成，无媒体错误。

Media 记忆可恢复；单击配音片段后仍为 Media，点击 WAV 仅打开素材预览。当前已生成结果及可见控件中未找到明确的“编辑配音结果/定位对应文稿”入口。手动选择 Voiceover 才能查看正确文稿，无法完成本例从结果进入配音编辑的流程。导航前后版本4及全部保存内容一致。

**预期结果**

提供明确的配音/旁白结果编辑入口；用户显式选择该入口后，应定位正确工程的 Voiceover 及对应文稿，优先于 Media 记忆，且不重新生成或改动工程。普通 WAV 预览和音频片段选择仍可保持其本来语义，本条不要求所有普通素材点击都自动切模块。

**影响**

生成结果与配音文稿之间缺少直接编辑定位，用户只能自行进入 Voiceover 查找目标，ERYE210-004 的结果入口流程未完成。
