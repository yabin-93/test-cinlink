# 【生产环境】【ERYE210-040】删除独立背景音频时，原视频和原声同一范围也被裁剪

云效：[FWXC-516](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=f319c777b70fbfb7010c5a15ad)；状态🤔AI提缺陷，负责人牛诗晴，生产环境。正文、字段及5个附件回读核验通过。

**现象**

仅删除独立背景音频A1时，原视频及原声同一时间范围也被裁掉，工程从20秒缩短为约18.61秒。

**前置步骤**

1. Windows / Google Chrome登录生产环境 https://app.cinlink.ai，账号具备视频工程编辑权限。
2. 新建专用项目、独立会话和工程，准备附件20秒原片E196-A.mp4，原视频和原声均从0秒起、1倍速，工程已保存。
3. 将附件A1-independent.wav准备为独立背景音频片段A1，从14秒起、长约1.393197秒，未与视频或配音句子绑定；时间线含字幕对照。

**提示词**

本次为编辑器页面操作，无Agent提示词、补槽或生成run。删除操作使用键盘Delete，不发送剪辑指令。

**复现步骤**

1. 打开上述新工程，确认预览总时长为00:20.00；原视频及原声覆盖0～20秒。
2. 在时间线找到背景音乐音轨的独立A1，片段范围为00:14.00～00:15.39，实际素材为附件WAV。
3. 单击A1片段，仅选择该音频片段，保持视频、原声和字幕未选中。
4. 按一次Delete，等待保存完成。
5. 查看时间线及预览总时长，核对原视频、原声的保留范围和字幕；保存本步骤失败现场。
6. 再点击一次撤销，核对A1、视频及原声是否恢复，区分删除失败与撤销表现。

**实际结果**

- A1被删除，同时原视频和原声也被裁去源14.000000～15.393197秒。
- 原视频和原声分别由一段变成两段：源0～14秒、源15.393197～20秒，后一段从时间线14秒接上。
- 工程总长变为18.606803秒，页面显示00:18.61，短了约1.393197秒；字幕保持原内容。
- 一次撤销可恢复完整轨道及20秒时长。现场工程已撤销恢复，查看旧工程时需重新执行第2～4步触发。

**预期结果**

只移除被选中的独立A1；原视频和原声保留0～20秒完整范围，工程仍为20秒，字幕和共享源素材保持。一次撤销应恢复A1。

**影响**

用户清除背景音频时会意外丢失同一时间范围的画面及原声，影响成片完整性。
