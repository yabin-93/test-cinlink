**现象**

工程只有音频、没有视频或图片画面时，Watermark/水印的文字输入仍可编辑，填写文字后实际保存，并在黑色预览区显示；页面没有无画面不可添加水印的限制说明。

**前置步骤**

1. Windows / Google Chrome登录生产环境https://app.cinlink.ai，使用具备工程编辑权限的测试账号。
2. 新建专用测试项目及独立会话/工程，准备一段真实WAV音频放入时间线，工程不含视频、图片或字幕轨。
3. 确认无已有水印，工程保存完成；本次音频时长约1.35秒。

**提示词**

无Agent提示词；通过编辑器页面操作，无补槽、无目标run。文字水印测试值：`AUDIO_ONLY_013`。

**复现步骤**

1. 打开新建的纯音频工程，核对时间线只有音频，预览区没有视频画面。
2. 依次进入Media/媒体、Scripts/文稿、Captions/字幕、Voiceover/配音、Watermark/水印，确认模块可浏览。
3. 在Watermark中选择“文字”，查看文字框及无画面限制说明；实际文字框可用，没有限制原因提示。
4. 在水印文字框输入`AUDIO_ONLY_013`，点击输入框外完成提交，等待保存结束。
5. 查看预览区及保存结果：黑色预览右上角出现同样文字，实际保存内容包含该文字水印，版本由1变为2。
6. 切换“图片”子页，观察上传入口；入口仍可用。本次未上传图片，不将该观察扩大为图片水印已保存。

**实际结果**

真实音频工程无视频/图片轨，但文字水印写操作可用且已持久化，文字为`AUDIO_ONLY_013`；工程保存版本1→2，未显示无画面限制或错误提示。截图显示同一约1.35秒纯音频工程及预览文字，附件JSON保留最终保存核验。

**预期结果**

纯音频、无可视画面时可以浏览Watermark模块，但添加/修改文字及图片水印的具体写操作应禁用，并明确说明需要视频画面；不得保存无画面的水印修改。加入有效画面后的水印能力应恢复。

**影响**

用户在没有画面的工程中仍能执行并保存水印配置，产生不符合能力前提的编辑结果，且无法从页面理解限制。
