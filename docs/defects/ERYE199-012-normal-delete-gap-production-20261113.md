**现象**

同一视频轨中，先将后段B向右移动、留出间隙，再对前段A执行普通Delete删除，B会自动前移5秒，原有时间布局被改变；本次没有选择波纹删除或删除空隙。

**前置步骤**

1. Windows / Ego Lite登录生产环境app.cinlink.ai，账号具备视频工程编辑权限。
2. 新建专用测试项目、独立会话及工程，导入附件原片（640×360、30fps、48kHz、约10秒）。
3. 在同一视频轨准备两个相邻片段：A在0～5秒、B在5～10秒，两者均使用附件原片源0～5秒、1倍速，确认已保存并加载完成。

**提示词**

缺陷触发步骤无对话提示词，使用页面拖动和Delete普通删除；无补槽。

以下为异常已经出现后才发送的独立波纹删除补充验证指令，不是触发缺陷的前置步骤或原因：

只编辑当前工程“ERYE199-012-2026-11-13T08-43-24-066Z”（工程ID：64a62954-134e-4b57-803a-517d4b422e3f），不新建工程、不生成替代视频。执行一次独立的“波纹删除空隙”：仅闭合当前唯一视频片段B（轨道384e990e-709a-4d4d-9e0c-d85ae993cd61，片段9de43eec-7833-4c88-8afa-22286ec4b62a）前方0～2秒的空隙，使B从0秒开始；保留源范围0～5秒、原片ID和片段ID。不用普通移动、普通删除、拼接或生成成片替代波纹删除；如不支持明确说明并保留工程。

**复现步骤**

1. 打开上述独立工程，核对同轨A为0～5秒、B为5～10秒。
2. 将播放头放到0.5秒，拖动B的片段主体向右移动2秒，不拖动裁剪手柄，也不把B移到其他轨道。
3. 等待保存完成，确认A仍为0～5秒、B为7～12秒，5～7秒形成2秒空隙，记录删除前截图。
4. 单击选中A，按键盘Delete执行普通删除；不要选择波纹删除、删除空隙或剪切命令。
5. 等待保存完成，观察B在同轨的起止位置、源范围和工程总时长，记录删除后截图。此时已经复现缺陷，无需发送任何Agent指令。
6. 可选补充验证：在异常已经出现后发送“提示词”中的独立波纹删除指令；本轮回复不支持该操作并未修改工程，不影响步骤1～5的复现结论。

**实际结果**

步骤3普通移动正确：B位于7～12秒，源范围0～5秒。步骤4普通删除A后，B自动变为2～7秒，起点前移5秒；源范围仍为0～5秒，工程时长由12秒变为7秒。B关联原声也位于2～7秒。页面时间线截图与保存结果一致。

后续补充任务为done，但明确“不支持独立的波纹删除空隙”，未提交修改；前移现象发生在该任务之前。截图中的黑色预览是播放头位于空隙，不作为额外播放故障。

**预期结果**

按ERYE199-012，普通移动、普通删除默认保留空隙。仅删除A后，B应仍位于7～12秒，0～7秒为空隙；只有显式的独立波纹删除动作才闭合间隙并改变后段位置。

**影响**

用户普通删除前段时，后段及关联原声发生未选择的时间位移，无法保持原先编辑时序和间隙。
