**现象**

将视频、音频或图片上传登记到工程素材库后，时间线仍为空，但“撤销”按钮不可用，无法单独撤销这次登记。三类素材均出现；后续放入时间线的动作可以撤销。

**前置步骤**

1. Windows / Ego Lite登录生产环境app.cinlink.ai，账号具备素材导入和工程编辑权限。
2. 新建专用测试项目，分别为视频、音频、图片准备独立会话和空白工程；每种素材测试前确认时间线为空，未执行其他编辑。
3. 准备附件640×360、30fps的约10秒视频和48kHz音频，并另备一张512×512 PNG图片（本轮使用cinlink-smoke-watermark.png）；不要预先放入时间线。

**提示词**

无。本例使用页面的“选择媒体”/“导入素材”、拖入和撤销按钮，不发送对话指令；无补槽。

**复现步骤**

1. 打开视频专项空白工程，点击“选择媒体”，选择附件ERYE199-video.mp4，等待登记完成。
2. 确认右侧“媒体→工程”出现该素材卡片、页面提示文件已保存到素材库；确认时间线仍为空、工程时长为0。
3. 检查时间线工具栏“撤销”按钮：当前不可用，无法撤销刚才的素材登记；记录截图。
4. 将该视频素材卡片拖到空时间线，等待放入完成；此时可以点击“撤销”移除本次放入，时间线重新为空。此处仅验证放入的撤销，不代表登记已撤销。
5. 打开音频专项的独立空白工程，使用ERYE199-audio.wav重复步骤1～4。
6. 打开图片专项的独立空白工程，使用cinlink-smoke-watermark.png重复步骤1～4。

**实际结果**

三类素材均可独立登记并放入对应轨道，放入动作均可撤销；但视频、音频和图片各自在“登记成功、尚未放入”阶段均没有可用的独立撤销操作。实测逐项结果见附件evidence.json。没有将空时间线的黑色预览当作播放故障。

**预期结果**

按ERYE199-008，“登记素材”和“放入时间线”应是两个可独立撤销的动作；登记完成但尚未放入时，也应能撤销刚才的登记，不要求删除源文件或影响其他工程。

**影响**

素材登记不具备需求要求的撤销语义，用户误登记后无法通过撤销恢复本次操作前状态。此缺陷不涉及放入失败，放入及其撤销已通过。
