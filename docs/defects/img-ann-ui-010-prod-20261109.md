# 图片200%视图平移尝试未生效 — FWXC-368

云效：[FWXC-368](https://devops.aliyun.com/projex/project/1e401ac99539c3999e00e40006/bug#openWorkitemIdentifier=7676dafe333fa5832e64c3441e)。通过官方OpenAPI新建1条，不做去重，旧项修改0。3张原始JPEG已上传并嵌入，正文、字段、附件ID/名称/字节数及图片引用回读通过。操作方式待确认，010仍Blocked。

**现象**

图片编辑器放大至200%后，原右下侧批注点位于可视区域外。关闭标注模式后，尝试左键拖动画布、滚动及空格拖动，均未观察到图片平移，未能通过这些操作将目标区域移入视区。页面未发现显式平移入口。本项提交用于排查平移能力及操作入口，有效手势尚待确认。

**前置步骤**

生产环境 https://app.cinlink.ai/ ，macOS / Google Chrome，有头登录测试账号 yabinc18（Creator）。专用项目 IMG-ANN-UI-007-20261109，独立010会话 6b0d3e7c-ef91-4d48-bcbb-4304fcbb61b2。
使用授权生成的人像 portrait.png（1254×1254，红色上衣、蓝色牛仔裤、黄色手包），导入后一次去背景建立图片工程，再选择带背景的源版本 editor_image_dc36b1a448df4111b705a59ca3c884b5；准备处理版本 editor_image_333734859d4a4aa4a6c37ab8175ae6cb。
在适应窗口状态，于画面右下空白地面创建批注1，实际粘贴完整正文并自定义对象“右侧空白地面”。平移尝试期间尚未添加引用或发送生成请求。

**提示词**

素材登记（准备）：IMG-ANN-UI-010素材登记：portrait.png。仅登记，不处理、不生成、不导出，后续通过页面批注工具测试。

批注正文：在这块区域添加一只小型棕白色小狗，坐在画面中人物右侧的空白地面上，四肢和身体结构自然，大小不超过人物高度的三分之一，不遮挡人物或黄色手包；保持人物面貌、身体、服装、手包、背景和画幅不变，仅允许小狗周边自然阴影变化。

平移由页面操作触发，不发送聊天平移指令。

**复现步骤**

1. 打开上述会话的图片编辑器，选择带背景的源版本。
2. 在适应窗口状态，创建右下侧批注并填写正文，确认编号、名称和正文。
3. 通过缩放菜单选择200%，点击原批注编号核对正文；批注点因放大处于当前视区外，浮层仍显示。
4. 关闭标注模式，在画布上尝试左键拖动，观察图片是否平移。
5. 继续尝试滚动及按住空格拖动画布，观察目标区域能否进入当前视区。
6. 对照操作前后的画布画面和200%缩放值。

**实际结果**

上述三种尝试均未观察到画布平移，目标区域未通过这些操作移入视区，页面没有发现显式平移控件。200%状态下正文仍可回读，未证明批注坐标丢失或错误。
随后返回“缩放以适应”，原构图恢复，正文/对象名保留；经浮层添加引用并仅发送一次生成，结果右侧新增棕白小狗，导出及重开成功。此正常分支不能代替平移后定位验收。
本问题发生于视图操作阶段，无对应失败生成run_id；不是生成失败。

**预期结果**

按 ERYE-237 §3.1“超出区域可平移查看”，放大后应可通过产品支持的操作将超出视区的图像区域移入视区，并保留批注定位。§5.2要求坐标逆变换考虑平移；A15要求缩放、平移、高DPI下创建批注和mask，回到源图后位置与直径一致。
应提供可用、可发现的平移方式；若已有其他专用操作，请明确入口或手势并据此复核。不要求某个未经需求指定的快捷键必然生效。

**影响**

当前测试无法在保持200%倍率时查看右下目标区域，平移后批注定位分支未完成；需退回适应窗口继续操作，影响放大状态下局部查看及批注操作的验证。
