# 【ERYE196-004】视频编辑器缺少对象/范围引用到Agent及逐项移除能力

**现象**

视频编辑器中可以多选视频、字幕及原声音频，但未找到将选中对象或时间范围引用到Agent输入框的可用交互，也未形成显示对象名称、时间范围且可逐项移除的引用标签。需求§03明确要求该功能；ERYE196-004按用户2026-11-13确认的需求口径判Failed。

**前置步骤**

1. 预发环境，有头Chrome，测试账号已登录；本项页面证据实际采集于2026-11-05。
2. 已保存工程“张雅婷(Tin)分享的视频.mp4”，约120.33秒，含视频、原声音频及148条原文字幕；Hello位于2.02～2.22秒，复测基线为版本9。

**提示词**

本项卡在对象引用入口，未发送Agent任务。原用例后续指令如下，仅用于说明未执行的步骤：

> 仅把已引用的C1原文改为欢迎使用 CinLink，其他内容不变

**复现步骤**

1. 打开上述工程，在时间线选择视频，按页面提示Shift多选原声音频与Hello字幕。
2. 查看选中对象操作与Agent创作框，查找将选中对象引用到Agent的可用方式。
3. Shift反选原声音频，保留视频和字幕，检查输入框是否有对象名称/时间范围及独立移除引用的入口。
4. 检查字幕右键和时间尺操作；核对文件级@候选是否实际提供字幕/音轨/时间范围对象引用，随后恢复选区及输入框。

**实际结果**

多选和反选可操作，反选音频后仍选中视频与字幕；输入框未显示可辨识的编辑器对象引用标签。字幕右键未找到引用操作，时间尺操作仅定位播放头，@是文件级候选，不能代表对象或范围引用。因有效引用未建立，逐项移除引用及后续Agent定点改文未执行，无本例run_id。

**预期结果**

按[ERYE-196需求](https://devops.aliyun.com/projex/req/ERYE-196)评论23563211第03节，用户可将选中的片段、字幕、轨道或时间范围引用到Agent；输入框可辨识对象名称和时间范围，并允许逐项移除。入口与文案可依实际设计实现，但必须有可完成此业务的交互。移除后只保留用户最终选择的引用目标。

**影响**

用户无法通过编辑器选区建立明确可管理的Agent对象引用；004的移除引用与最终目标约束流程无法继续验证。
