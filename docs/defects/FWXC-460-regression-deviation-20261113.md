**现象**

背景修改为指定纯蓝和纯绿后实际颜色不均匀且RGB不符

**前置步骤**

生产app.cinlink.ai，Chrome有头，yabinc92 Creator。项目d15de3bc-fa92-431b-8e8f-dbed3d151a22；会话https://app.cinlink.ai/c/9cefda66-0793-41d9-817b-3f38694307d7 。原授权11.png为1024×1024白底红纸船。遵用户最新005规则，以未去背景原图为源，编辑器建立并保存白底源版。

**提示词**

ERYE237-005第一步：在当前已打开的图片工程“11.png”上，以当前未去背景、保留白色原背景的原始图片为源，将背景改为纯蓝色RGB(0,0,255)，保持红色纸船的形状、颜色、位置不变，保持1024×1024尺寸，生成并保存为这个图片工程的新版本。只处理这一张图，不新建无关工程，不导出；完成后停止，等我确认再继续下一步。

ERYE237-005第二步：第一步蓝底版本已保存。请明确以当前“11.png”工程刚完成的蓝底结果为源，仅将蓝色背景改为纯绿色RGB(0,255,0)，保持红色纸船形状、颜色、位置不变，保持1024×1024，保存为同一图片工程的新版本。不要回用白底原图，不新建其他工程，不导出；完成后停止。

**复现步骤**

1. 发送第一步完整指令一次，要求纯蓝RGB(0,0,255)。
2. 等蓝版保存后导出实际PNG。
3. 明确以当前蓝版为源发送第二步完整指令一次，要求纯绿RGB(0,255,0)。
4. 等绿版保存后导出PNG，检查背景及实际颜色；刷新查看三版保留。

**实际结果**

**预期结果**

按明确RGB生成均匀纯色背景，分别满足(0,0,255)及(0,255,0)，不在纯色区域引入纹理或色块。

**影响**
