## MW-21：同一项目内两个会话复用素材的执行准备

本例验证**同一账号、同一项目 P 内，会话 B 复用会话 A 已登记的原始视频**。不测试两个非项目会话、跨项目复用或直接继承 A 的聊天上下文。

### 固定素材

- 目录：`E:\图片视频素材\talecast测试素材\不同的内容\单音频轨道`。
- 本例文件：该目录下的 `7MB.mp4`，7,815,126 字节，约 60.5 秒，1280×720，包含中文语音及音轨。
- 后端可能去重或改名；文件身份以**本次上传/登记返回的 file_id** 为准，同时记录服务端保存名。不要硬编码历史 file_id，也不要仅按本地文件名判断。

### 前置条件与准备步骤

1. 登录预发，使用同一专用测试账号；没有同账号的其他预发任务；余额足够完成字幕及渲染。确认本地素材可读取。
2. 通过项目入口新建独立测试项目 P，名称可用 `MW21-跨会话复用-<日期时间>`，记录 project_id。必须进入该项目，**不要点击“新建非项目会话”**。
3. 在 P 内新建会话，记作 A，记录 conversation_id=A；核对 A 归属 P。界面不能命名时直接以 ID 区分，不依赖会话标题。
4. 在 A 上传 `7MB.mp4`，用 `@` 选择这次附件，然后发送：`请记录我引用的视频素材，只回复素材文件名，供本项目的后续会话处理；本条不执行编辑或生成。`
5. 新版上传可能到发送时才发生，不能只看本地缩略图就认为准备完成。等待云端上传、源消息保存完成；从素材详情或上传完成响应记录 file_id=F、服务端保存名。**会话附件不等于项目素材**：夹具使用当前产品的 `POST /cloud-tool-api/v1/projects/{P}/files` 将已经上传的 F 关联到 P，再 GET 同一路径确认仍为 F；这一步只登记归属，不再次上传字节。确认源消息引用 F，且 P 的文件清单包含 F；未拿到这些证据则准备未完成，不继续。
6. 回到**同一个项目 P**，在项目内再新建空白会话，记作 B；核对项目选择器与 URL 中的项目 ID 均为 P。当前产品空白会话先作为草稿存在，首次提交时才分配并持久化 conversation_id=B；提交后必须回读 B≠A 且 A/B 的 project_id 都为 P。若引用检查失败、B 尚未持久化，证据记“P 内空白 B 草稿”，不能编造 B ID。不要另建项目或非项目会话，不在 B 重新上传、拖入本地文件或复制 A 的附件。
7. 至此准备完成。**B 能否检索 F 是待验证步骤，不作为已满足的前置条件。** 源会话和素材必须保留到本例验收结束，不能在切换到 B 前清理。

### 正式执行与验收
