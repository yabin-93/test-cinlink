## 需求摘要

- 以自然语言检索当前项目已分析的视频，使用当前项目对话框；不依赖旧“素材与生成 → 本地素材查找”卡片。

1. 用户提供功能完成信息、素材路径及P0范围，未提供正式PRD；以下主链路按本地实现编写，隔离、异常及状态残留场景标明QA风险来源。
2. 本地前端 `E:\proj\cinlink-studio-web\src\app.js` 的 `runWorkspaceMaterialSearch`、`workspaceAnalyzedLibraryScopeFor` 与 `workspaceMaterialSearchReply` 显示：搜索当前项目已分析素材、区分无结果与请求失败、保留匹配时间和依据、将候选暂存到输入上下文（均为旧实现线索，非当前UI必需展示契约）。`src/lib/material-search-presentation.js` 及其测试提供结果持久化/去重依据。**旧源码只作设计线索，验收以当前实际业务能力为准。**

4. 业务按真实候选、实际内容及可用性验收；旧内部路由、源ID、时间字段不作当前UI硬条件。固定脚本映射见用例表。

## 能力边界

- 固定脚本映射按自动化/脚本列维护；人工或有头操作完成不代表固定脚本已实现。
- 声音和画面文字的查询必须有独立听审/读审依据，不用ASR、元数据或少量抽帧自证；不能虚构OCR关键词。
