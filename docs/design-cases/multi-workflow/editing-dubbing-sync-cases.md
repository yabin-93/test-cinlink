# 剪辑、配音与字幕同步 P0 用例

更新：2026-11-05。统一入口：[全部测试用例](../../cases/README.md#剪辑配音与字幕同步p0)。新增 **SYNC-001～006，共6条P0；0 AUTO / 6 PLAN，全部未执行**。独立于MW和SSO编号，不改原22条SSO定义及历史结果。

## 需求摘要

- R1：先剪辑，再对剪辑结果翻译配音并添加同语字幕，验证新声音、字幕与保留内容一致。
- R2：先翻译配音并添加同语字幕，再剪辑，验证已有声音和字幕随画面一起裁切、移动。
- R3：去口癖或多素材拼接后，再翻译配音并添加同语字幕，验证删除点、拼接点及累计时间变化。
- 每类2条；每例两轮，便于分别核验中间产物P1与最终成片P2。每轮完整提示词一次发送；第二轮显式处理P1。只测试会话任务、产物及下载文件，不依赖尚未完成的编辑页。
- 用户已确认：**先按可观察问题验收，暂不设毫秒阈值**。配音音色克隆和人物口型同步不在本批验收范围。

## 通用前置 P

1. 专用账号登录预发工作台、积分充足；同账号无并发任务。每例新建独立项目和会话S；上传该例指定素材，等待可用，登记文件名、文件ID、SHA、实际时长及会话/项目ID。单素材例别名F；SYNC-006分别登记A/B。纯文本明确文件名及文件ID，不依赖@候选。
2. 每例各轮都在S内完成。运行中等待终态后再发送下一轮；合法计划确认、补槽按本例参数填写并继续，记录问题、填写值、确认计划及截图。补槽不能将P1换回原片或把本例改为另一个工作流。
3. 当前版本需支持本例使用的剪辑/去口癖/混剪、源语言识别、目标语言配音及字幕烧录。尤其执行SYNC-004前核对日语源视频到中文配音能力；若服务不可用或当前版本明确不支持，记录实际提示及前置受阻，不静默换文件、换语言或用合成结果代替真实服务端结果。
4. 逐个预听所用语音素材；按时间记录原句、画面特征及换句/换镜头处。新闻标题、品牌词由人工校对；需要目标语言能力的人员审核翻译与配音。ASR仅作辅助，不能用同一被测ASR输出同时充当标准和结果。M3有双人画面不等于选中片段一定存在两人交替发言，不据此验收多说话人音色保持。
5. 每轮返回后保存本轮文件ID、SHA、run_id、执行计划和产物归属；把中间视频登记为P1、最终视频登记为P2。下一轮提示词中所有花括号变量均替换为本例已记录的真实文件名/ID，再一次性发送。不得发送未替换的模板。

## 通用执行与验收 E

1. 两轮分别达到成功终态；P1/P2必须属于本例本轮且能完整播放、下载与解码。最终交付为一个MP4，画面、目标配音及新字幕同时可见/可听；只有分别返回音频、字幕或助手声称完成，不算完成成片交付。
2. 核对执行来源及实际内容：第一轮从F（或A/B）处理，第二轮实际输入P1，不误用原片、历史视频或别例产物。保留P1文件，第二轮后再次回读SHA不变。不能仅凭文件名或助手回复证明来源正确。
3. 剪辑轮目标时长按已有高光口径±2秒核对；配音字幕轮不再次剪辑，视频时间线长度相对其输入按现有保时长口径±0.5秒核对。两者是时长检查，不替代同步验收，也不是新增毫秒同步阈值。画面比例沿用该轮输入；不拉伸，不无故截断/丢弃内容。
4. **完整听看P2**，逐句对照目标语言配音和新字幕，确认译义对应、语言正确、句序一致，无漏句、重复句、已删内容回流、明显错字或未完成字串。原有新闻文字、日文烧录字幕属于原画面基线；不要求自动抹除，不把它们当作新加目标字幕。
5. 除逐句检查，专门复核首句、25%/50%/75%附近完整句、末句，以及全部实际删除/拼接点前后至少1秒。记录字幕显示起止、对应配音起止和观察到的偏移；**字幕不得明显先于或落后于对应配音，不得越播越偏；剪切处不得截断音节、残留上句字幕、插入无来源语音或出现意外静音/黑帧**。暂不设毫秒阈值，保存原始观察值及判断依据，不据估计值宣称达到某个毫秒标准。
6. 若任务同时交付SRT，核对时间非负、顺序递增、各条结束不早于开始且不超过P2时长；文字和烧录字幕一致，时间从P2的0点计算。不能沿用原片/P1绝对时间造成字幕越界。SRT作为辅助证据，不强制要求当前服务尚未提供的独立导出能力；无SRT时从实际成片逐句听看记录，不能因此省略同步验收。
7. 人工根据源视频与实际剪辑结果建立保留片段表：源文件ID、源起止、P1起止、删除点/拼接点及对应语句。无EDL时通过画面/音频比对建立，不把“目标30秒”假定为“源片前30秒”。先配音再剪辑时，特别比对P1/P2声音，确认是同一已有配音的相应片段，未擅自重新配音或更换声线。
8. 失败保存本轮真实页面截图和实际成片失败帧，附对应时间码、原片/P1/P2关联、必要音频/SRT与任务错误。语义/同步核验缺听审或文件缺失则标“待复核”，不可仅凭done判通过；R1失败则R2记依赖阻塞，不换输入凑结果。
