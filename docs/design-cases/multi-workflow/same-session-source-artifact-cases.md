## 前置P与执行E

1. 专用测试账号登录预发，余额可覆盖本例；无同账号并发测试。每例新建一个非项目会话S，5轮始终留在S。
2. 原片F：`E:/图片视频素材/talecast测试素材/不同的内容/单音频轨道/7MB.mp4`，英文语音、约60.5秒、1280×720、有音轨。核对实际D/W/H、SHA-256及原始画面，不含本例新增字幕和测试水印。
3. 每例只上传一次F，发送准备消息：“保存我上传的原始视频供本会话后续处理，本条只登记素材，不执行剪辑、字幕或增强任务。”登记不计入5轮；记录真实S/F及setup run，云端原片与本地SHA-256一致。
4. 以下5轮均不@、不附文件、不点产物引用或继续加工，只发送各轮完整正文一次。V1～V5是测试记录代号，不额外拼入提示词；第N轮不包含登记消息。水印使用默认样式，全程可见。
5. 等上一任务终态并取证后再继续；出现补槽按该轮指定来源/参数填写并保存问题、答案、截图后继续，不静默替换来源。
6. 每轮记录提示词、无引用标签截图、run_id、计划及运行根工具实际输入、产物ID/文件名/SHA-256、终态和媒体参数。原片轮输入F；产物轮须绑定指定轮次的真实MP4，不能仅由共同F祖先判正确。允许本轮内部中间文件及有明确来源的缓存；禁止其他历史分支直接串入。
7. 当前轮交付一个MP4；解码核时长/尺寸/音轨，首中末原始帧核字幕/水印位置及保留/残留情况，字幕必要时对实际SRT全文及语音。高光目标±2秒；不改时长操作与实际输入±0.5秒；2倍增强为2560×1440。不能仅凭done或脚本通过判完整内容通过。
8. 依赖轮没有done且可解码的唯一MP4时，本轮记阻塞且不提交，不回退原片或其他产物；仍执行后续独立F轮。原片及全部历史产物可回读、SHA-256不变，不重发已受理任务。失败/阻塞保存当轮真实页面截图，内容问题另保存原始视频帧；证据缺失须明确记录。

## 自动化与范围

`npm run test:sso:mixed`：仅019～022，有头、单worker、零重试。`npm run test:sso -- --grep "SSO-020"`可单例选择。

源文件由`tests/sso/cases/source-artifact.ts`维护，公共执行器支持逐轮inputRound、指定依赖缺失阻塞、实际输入来源审计、完整历史哈希、截图与trace。脚本AUTO只说明接入；最终结果取本批记录，不影响001～018和默认staging计数。

本次不覆盖并行重叠发送、失败注入、跨会话/项目复用、多原片或超长会话，不据此宣称全部上下文场景覆盖。精确字幕语义、画面效果及声音保留另按实际媒体复核。
