## 通用前置与执行口径

1. 专用账号已登录、积分足够且无并发任务；每例新建独立非项目会话S，例内5轮始终在S。准备本机可读的7MB.mp4：英文语音、约60.5秒、1280×720、有音轨；核实真实文件及语言，记录SHA-256、实际时长/尺寸、会话ID。
2. 每例仅上传一次原片F，等待上传完成并登记真实file_id。准备消息：“保存我上传的原始视频供本会话后续处理，本条只登记素材，不执行剪辑、字幕或增强任务。”准备消息不计入5轮。
3. 每轮完整提示词一次发送，不@、不附加文件、不点击产物引用。V1～V5仅是记录代号，对应正式第1～5轮MP4。逐轮等待终态、下载并核验后再继续。遇补槽按该轮指定来源及参数填写并继续，记录问题、答案、计划确认和截图。
4. 来源列是本轮顶层输入：F为最初上传原片，Vn为本例第n轮实际视频产物。保留真实文件ID、run_id、计划与工具输入证据；不能仅凭助手回复或同一原片祖先认定来源正确。历史分支不得被最近产物替代；原片轮不得直接用旧SRT作为顶层输入。允许本轮内部必要中间产物。
5. 每轮交付一个可下载、完整解码的MP4。剪辑目标时长±2秒；不剪辑轮相对实际输入时长±0.5秒；默认保留输入尺寸，2倍增强须为2560×1440。逐段比对画面及音轨，确认保留片段、顺序与要求一致；字幕逐句对照语音检查语言、译义、时间轴及明显漂移，首中末和所有剪切点另行复核。不能仅凭done判通过。
6. 水印默认样式、指定位置且全程可见；抽查首中末画面并检查历史水印/字幕残留。无新增字幕或水印不等于清除原片固有文字。对照每轮输入建立新增效果基线。
7. 保存提示词、来源、产物ID/文件名/SHA、实际参数和截图；旧产物仍可回读且SHA不变。依赖视频缺失/失败则相应轮记Blocked，不换来源、不自动重发；后续独立F轮可继续。未执行为Not Run，缺少来源或内容证据为待复核，不冒记Passed。

## 自动化入口与边界

- 数据定义：`tests/sso/cases/editor-operations.ts`；执行器：`tests/sso/same-session-original.spec.ts`。
- 仅枚举新增5条：`npm run test:sso:editor -- --list`。真实执行：`npm run test:sso:editor`，有头、串行、零重试，会提交任务并可能计费。
