## 需求摘要与确认口径

- 一个用例始终使用同一会话 S、一个上传的原始视频 F。一个用例内可以发送多轮指令，每轮均不输入@、不选择素材引用标签，直接用纯文本明确处理最初上传的源视频F；不重新上传、不选择上一轮成片。
- 单工作流：**每轮只要求一种业务处理；SSO-001～004各轮工作流可以不同，SSO-005～008每例5轮固定同一种工作流**。例如第一轮明确处理源视频生成字幕，完成后第二轮仍明确处理该源视频剪高光，仍属于“每轮单工作流”场景；两轮都以F为输入。SSO-001～004每例内不重复同一种工作流；005～008分别固定添加字幕、翻译配音（语音及字幕模式）、文字水印、高光剪辑；005内部转写/字幕翻译/烧录、006内部翻译/配音/字幕均按对应产品业务工作流计，不算跨工作流穿插。一个业务工作流内部包含多个工具调用，不因此算多工作流。
- 多工作流：一轮指令对同一个原片组合处理，最终成片同时包含要求的多个效果。例如字幕＋水印交付一份同时有字幕和水印的 MP4，不能拆成一份字幕成片和一份水印成片来替代。
- 下一轮仍从 F 开始，不继承上一轮成片上的水印、字幕、剪辑时长或增强倍率。内部实现是否生成临时文件不作限制；验证的是本轮输入来源、处理要求与最终组合结果。
- 前置将“源视频”绑定为本会话最初上传的7MB.mp4；各轮直接使用下表正文，不恢复统一提示词前缀。发送后核验实际处理是否回到F，不能仅由文字称呼推断来源正确。此前“继续处理这个视频”未指定来源时默认最近一次成功产物的规则不用于本组原片处理。

本节以用户最后纠正“多工作流对原片处理，不是分别处理”为准，替代讨论中的“各工作流独立输出”解释。

## 假设、测试数据与前置操作

### 通用前置 P

1. 使用专用测试账号登录预发工作台，余额覆盖本例预计费用，无同账号并发执行。每个用例单独新建空白会话 S；所有轮次均留在 S。若 S 属于项目 P，则全程固定 P，不切换项目或新建第二个会话。
2. 原视频采用 `E:/图片视频素材/talecast测试素材/不同的内容/单音频轨道/7MB.mp4`。已核对为**英文语音**，约60.5秒、1280×720、带音轨；不能写成中文语音。执行前核对实际规格，记录本地 SHA-256、D/W/H、首/中/末段语音与画面参照。F 中不能预先存在本例测试水印（包括`SSO-`、组合用例的`C1-`～`C6-`及恢复用例的`REC-`标记）或本例新增烧录字幕。
3. 仅上传这一个原始视频。发送准备消息：“保存我上传的原始视频供本会话后续处理，本条只登记素材，不执行剪辑、字幕或增强任务。”等待上传及登记完成，记录 S 的 conversation_id、当次 F 的 file_id 和云端保存名。若产品忽略准备指令、启动真实处理，先记录并恢复干净会话，不能把该处理产物当 F。
4. 登记完成后保持同一S，确认输入框无附件、无素材引用标签。各处理轮不输入@、不打开素材候选、不重新上传。先用登记记录确认F可追溯；发送后再从本轮计划/工具输入核验实际处理来源。
5. 下表引号内直接复制各轮正文，正文已明确处理源视频；不再拼接统一前缀。发送前截取完整文字及无引用标签的输入框，仅输入正文一次，不额外插入F的file_id或附件。

### 通用执行与验收 E

1. 各轮按编号顺序执行；除 SSO-016 专测执行中刷新外，上一轮到终态并完成取证后才发下一轮。有计划确认时核对原片和参数再确认；有补槽时填写本轮已给出的语言、时长、位置等，保存问题、答案和截图后继续。
2. 工具运行中保存输入快照；部分工具完成后会将input_media_context更新为输出，不能只读终态来证明来源。每轮记录发起时间、完整纯文本消息、无引用标签截图、关联 run_id、计划/工具实际输入F、终态、最终交付物 ID/名称及下载 SHA-256。续跑或确认可能沿用原 run，不将工作流数量等同于 run 数量，不要求每个工具各创建一个 run。
3. 本轮顶层输入必须是 F；由本轮内部步骤生成的临时文件可以参与本轮组合处理。不得把**之前任一轮**成片、SRT或配音当成本轮输入；组合分支和当前轮内部中间文件须逐级追溯F。只看名称或助手文字不足以证明来源；缺少调用/计划证据时记来源尚未核实，不能判完整通过；不得用请求没有file_id或助手声称处理原片作为正确来源证据。纯文本提交不强制请求正文携带F，核验的是实际计划/工具输入。
4. 最终交付按**当前轮次**核对，不把历史卡片补计为本轮产物。要求组合成片时，必须打开同一个 MP4 核对所有效果；分别交付两份各含一种效果的视频，不能判通过。内部中间产物不强制要求显示或隐藏。
5. 视频须可下载、可解码；无剪辑时沿用现有测试口径 D±0.5秒。005保留原英语音轨，006及014的译制轮替换为本轮目标语言配音并配同语字幕；014返回原英语的轮次恢复F原音轨，其余按本轮指令保留音轨；指定高光时长时按该轮目标±2秒核对。2倍增强须为2560×1440，不能累计成5120×2880。这些是本工程既有测试判定口径，不作为新增产品规格声明。
6. 水印文字、位置和覆盖区间检查开头/中段/结尾帧；检查有无上一轮新增水印。字幕抽查首/中/末语音，核对语言、内容、时间轴及烧录/独立SRT交付方式；字幕时间不得超出其对应视频时长，无语音处不要求强行产生字幕。不能只凭后缀或字幕条数判通过。SSO-006及SSO-014译制轮另须听审/独立ASR核对本轮配音语言、语义及其与字幕的同步，不能只凭音轨存在或语言标签判定译制成功。
7. 前一轮结果及文件 ID 应仍可查询/下载，当前轮不得覆盖历史文件内容；同参数任务可产生相同内容或命中缓存，不强制文件字节变化。任务及产物应留在同一 S；后续轮次不新增原视频上传。
8. 保存每轮提交前、补槽/确认、终态截图及来源/产物审计；使用当前批次证据。余额变化只能记录事实，未取得按任务关联流水时，不宣称已验证扣费次数。
