# 图像编辑能力 · 测试用例（ERYE-237）

> 需求：云效 `ERYE-237《【全】图像编辑能力新增》`
> 来源章节：3.1 版本与视图 / 3.2 画笔文字形状 / 3.3 图上批注与对话引用 / 3.4 移除背景、AI 擦除、比例 / 3.5 处理状态与导出
> 说明：技能目录中没有“需求转用例”的专用 skill（`yunxiao-defect-sync` 只用于缺陷同步），本文件按现有设计用例规范编写。

## 一、打开与版本（3.1）

| 编号 | 优先级 | 前置条件 | 操作步骤 | 预期结果 | 来源 |
|---|---|---|---|---|---|
| IE-001 | P0 | 已登录；会话中存在至少一张图片 | 在会话中找到图片卡片 → 点击缩略图 | 打开图像编辑器；画布加载该图；标题/文件名与版本正确 | 3.1 |
| IE-002 | P0 | Agent 已生成或引用一张图片，图片卡片可见 | 对 Agent 说“打开第 2 张图” → 观察打开对象 | 打开指定图片；document/asset/version 与第 2 张一致；不落到“最后一张” | 3.1 |
| IE-003 | P0 | 已从图片卡片或 Agent 打开编辑器 | 打开编辑器 → 读取当前上下文绑定 | conversationId、documentId、assetId、versionId 均非空且与来源一致 | 3.1 |
| IE-004 | P1 | 同一文档存在 2 个以上版本 | 打开版本列表 → 查看缩略图顺序与标签 | 按派生关系与生成时间排序；编号/文件名/引用显示确切 versionId | 3.1 |
| IE-005 | P0 | 已打开图片并完成一次生成 | 对同一图片再次生成 → 查看文档与版本列表 | 新结果追加到同一文档；版本数 +1；旧版本保留 | 3.1 |
| IE-006 | P0 | 文档存在历史版本，且其后还有更新版本 | 选中历史版本 → 继续编辑 → 发送 | 产生新分支；其后版本不被覆盖；版本树显示分支 | 3.1 |
| IE-007 | P1 | 已提交一次生成，任务处于处理中 | 查看缩略图与导出按钮 | 缩略图为 job 占位；导出禁用；成功后变为可导出 | 3.1 |
| IE-008 | P1 | 已打开图片，画布与缩放控件可用 | 切 100% → 适合窗口 → 平移 → 缩放后查看批注/笔迹位置 | 仅视图变化；分辨率/坐标/导出不变；批注与笔迹跟随图像 | 3.1 |
| IE-009 | P2 | 窗口宽度较小（如 < 1024px） | 缩小窗口 → 收起项目导航 → 收起编辑区 | 优先收起导航；选中版本、草稿、引用保留；展开后恢复 | 3.1 |

## 二、画笔、文字、形状与本地编辑（3.2）

| 编号 | 优先级 | 前置条件 | 操作步骤 | 预期结果 | 来源 |
|---|---|---|---|---|---|
| IE-010 | P0 | 已打开图片；未处于其他工具模式 | 点击“画笔” | 主工具栏替换为 D04；输入框出现“画笔”引用标签 | 3.2 |
| IE-011 | P0 | 已进入画笔模式，未做任何绘制 | 切换模式后直接发送 | 不产生图片、不调用图像服务、不计费；空草稿被拒绝 | 3.2 |
| IE-012 | P0 | 已进入画笔模式，画布无实际修改 | 点击发送 | 拒绝提交并提示需要实际修改；不创建任务 | 3.2 |
| IE-013 | P0 | 已进入画笔模式，画布上存在可选中对象 | 选择对象 → 拖动 → 拉边界 → 删除 | 命中当前草稿对象；objectId 稳定；底图不可被当作文字/形状编辑 | 3.2 |
| IE-014 | P0 | 已进入画笔模式并选择自由画笔 | 画一笔 → 撤销一次 | 记录点列/颜色/宽度；一笔等于一个撤销单元；撤销后整笔消失 | 3.2 |
| IE-015 | P1 | 已进入画笔模式并选择自由画笔，画布有笔迹 | 落笔后连续移动 pointer → 撤销 | 历史不逐点增长；一次撤销回到落笔前；无中间残影 | 3.2 |
| IE-016 | P0 | 已进入画笔模式并选择文字工具 | 新建文字 → 改位置/字号/颜色/边界 | 属性全部生效；支持中文；边界可调整 | 3.2 |
| IE-017 | P1 | 已创建一段中文文字对象 | 预览 → 导出 | 预览与导出一致；字体解析与排版一致；无乱码 | 3.2 |
| IE-018 | P0 | 已进入画笔模式并选择形状工具 | 依次绘制线段/箭头/矩形/圆形/三角形/星形 | 六类形状可创建；保存类型/几何/样式，不只截图 | 3.2 |
| IE-019 | P1 | 画笔模式，已选中可上色对象 | 打开颜色面板 → 选色板 → 调色相/饱和度 → 输入 RGB | 颜色应用到选中对象；RGB 值与显示一致 | 3.2 |
| IE-020 | P1 | 画笔模式，颜色面板与吸管可用 | 选吸管 → 采样对象与批注附近 | 取合成结果；排除光标、批注、遮罩、棋盘格 | 3.2 |
| IE-021 | P1 | 画笔模式，已选中对象 | 拖动宽度/字号/擦除直径滑杆 → 缩放画布 | 按源图单位记录；缩放不改变实际尺寸 | 3.2 |
| IE-022 | P0 | 画笔模式，画布上有自由笔迹 | 用画笔橡皮擦局部擦除 | 仅擦本草稿；底图与已扁平化内容不变；可撤销 | 3.2 |
| IE-023 | P1 | 画笔模式，画布上有文字或形状对象 | 橡皮擦点击文字/形状 | 对象整体删除；底图不受影响；可撤销 | 3.2 |
| IE-024 | P0 | 画笔模式，存在可撤销的操作 | 连续绘制 → 撤销×3 → 重做×2 | 共用历史栈；按钮按可用性禁用；AI 结果撤回不重新调用模型 | 3.2 |
| IE-025 | P0 | 画笔模式，存在尚未发送的修改 | 点击关闭工具 → 选择“关闭弹窗”/“继续编辑” | 按 D06 提示；两种选择都保留草稿 | 3.2 |
| IE-026 | P0 | 画笔模式，已完成至少一笔绘制 | 纯绘制发送（不含生成指令） | 确定性渲染新版本；不调用付费模型；处理结束后完成 | 3.2 |
| IE-027 | P0 | 画笔模式，已圈选或框选一个区域 | 输入“把圈出的内容替换为蓝色” → 发送 | 进入 AI 编辑而非纯绘制；提交包含区域与指令 | 3.2 |
| IE-028 | P2 | 画笔模式，画布上存在对象 | 将对象角色设为 guide → 发送 | 仅作指示不烘焙；结果不包含该对象 | 3.2 |
| IE-029 | P1 | 已完成一次 AI 生成，结果版本已加载 | 尝试选中已融合内容继续编辑 | 不能当原对象编辑；原草稿可从历史恢复 | 3.2 |

## 三、图上批注与对话引用（3.3）

| 编号 | 优先级 | 前置条件 | 操作步骤 | 预期结果 | 来源 |
|---|---|---|---|---|---|
| IE-030 | P0 | 已打开图片并进入批注模式 | 在图像有效区域点选 | 立即出现编号点与浮层；annotationId 稳定 | 3.3 |
| IE-031 | P0 | 已打开图片并进入批注模式 | 点击图片外灰色区域 | 不创建批注；无编号点与浮层 | 3.3 |
| IE-032 | P1 | 已创建批注草稿，对象候选尚未返回 | 候选未返回时输入评论 | 可继续输入；不阻塞；候选返回后不覆盖已输入文本 | 3.3 |
| IE-033 | P1 | 已创建批注草稿，对象识别失败 | 写评论并添加 | 名称显示“对象 1”等占位；仍可添加 | 3.3 |
| IE-034 | P0 | 已创建批注草稿并输入评论 | 点击“添加到对话” | 输入框增加“对象名：评论”引用；不执行、不建任务；画布保留编号点 | 3.3 |
| IE-035 | P1 | 已创建至少一个批注草稿 | 增加第 2、3 个点 → 点引用标签 → 点画布点 | 点、浮层、标签双向联动；选中态同步 | 3.3 |
| IE-036 | P0 | 同一批注已存在草稿或已添加到对话 | 重开同一批注并修改评论 → 保存 | 更新原标签；不重复追加 | 3.3 |
| IE-037 | P0 | 已有草稿批注及其引用标签 | 删除草稿批注 | 编号点与引用标签同时移除 | 3.3 |
| IE-038 | P0 | 已有完整批注草稿（点、评论、对象） | 点击发送 | 冻结批注、对象绑定、源版本、全局指令；形成不可变消息引用与 submission | 3.3 |
| IE-039 | P0 | 已发送一次批注提交 | 查看发送成功/失败后的草稿 | 成功清空已提交引用；失败保留草稿可重试 | 3.3 |
| IE-040 | P0 | 已发送过批注消息，历史消息存在 | 发送后继续编辑草稿 | 历史消息不被改写；草稿修改不影响已发送内容 | 3.3 |
| IE-041 | P0 | 已有 10 条批注草稿 | 点选第 11 条 | 阻止并提示上限 10；已有 10 条不丢失 | 3.3 |
| IE-042 | P0 | 已创建批注草稿，输入框可编辑 | 输入 2001 字正文 / 全局 4001 / 合计超 12000 | 按服务端限制拦截；提示明确；已输入内容保留 | 3.3 |
| IE-043 | P1 | 已创建批注草稿，对象标签可编辑 | 输入 81 字对象标签 | 拦截或截断；不保存超长标签 | 3.3 |
| IE-044 | P0 | 会话中存在两张以上图片且都打开过 | 同时引用两张图片后发送 | 拆成两个独立 submission；不把一条批注应用到多图 | 3.3 |
| IE-045 | P0 | 已打开图片，输入框可用 | 输入“这里写的是什么” | 走图片问答；返回文字与位置引用；不建新版本、不调编辑模型 | 3.3 |
| IE-046 | P1 | 已打开图片，输入框可用 | 输入“把这里改成中文” | 走编辑；生成新版本；费用只归编辑 | 3.3 |
| IE-047 | P1 | 已打开图片，输入框可用 | 输入“先解释这里，再改成中文” | 拆成问答+编辑两步；可追踪；费用只归编辑 | 3.3 |
| IE-048 | P1 | 已打开图片，输入框可用 | 输入“记一下，先别改” | 只保存批注草稿；不执行 | 3.3 |
| IE-049 | P1 | 已创建编号点与选区 | 导出成品图 | 导出图不含编号点、浮层、选区、棋盘格 | 3.3 |
| IE-050 | P2 | 已完成一次生成，存在历史批注消息 | 查看旧锚点与新图 | 锚点不自动复制到新图；历史消息可打开原版本与原批注 | 3.3 |

## 四、移除背景、AI 擦除、比例（3.4）

| 编号 | 优先级 | 前置条件 | 操作步骤 | 预期结果 | 来源 |
|---|---|---|---|---|---|
| IE-051 | P0 | 已打开图片，工具入口可见 | 点击“移除背景” | 建立引用，可追加前景保留要求；单击本身不调用服务商 | 3.4 |
| IE-052 | P0 | 已提交一次移除背景任务 | 等待任务完成并查看产物 | 输出带真实 alpha 的新版本；保留主体与必要半透明边缘 | 3.4 |
| IE-053 | P1 | 移除背景结果已生成，预览为透明 | 查看透明预览与导出文件 | 预览铺棋盘格；导出文件不含棋盘格 | 3.4 |
| IE-054 | P0 | 已打开图片并进入擦除工具 | 涂抹 → 补涂 → 撤销 → 调整直径 | 显示半透明遮罩；补涂/撤销/直径均生效 | 3.4 |
| IE-055 | P0 | 已进入擦除工具，未涂抹有效区域 | 直接发送 | 拒绝提交；提示需要有效擦除区域 | 3.4 |
| IE-056 | P0 | 已进入擦除工具并涂抹有效 mask | 提交擦除 | 底图+mask+意图提交 AI 填补；不得把像素 alpha 设为 0 | 3.4 |
| IE-057 | P0 | 已打开图片并进入比例调整 | 选择 9:16 / 3:4 / 1:1 / 4:3 / 16:9 | 引用标签包含目标比例值 | 3.4 |
| IE-058 | P1 | 已选择过一次目标比例 | 重复选择另一比例 | 只更新同一草稿操作；不追加多个引用 | 3.4 |
| IE-059 | P0 | 已选择目标比例，输出尺寸已展示 | 提交比例调整 | 保持主体、扩展画布；不拉伸主体；输出尺寸与展示一致 | 3.4 |
| IE-060 | P1 | 已有批注草稿与全局意图 | 组合提交批注与全局意图 | 阶段顺序明确；依赖新图时重新定位，不沿用旧坐标 | 3.4 |
| IE-061 | P1 | 图片中包含文字或品牌信息 | 执行文字翻译 | 保留品牌名、Logo、用户指定文本；可先给替换表校正 | 3.4 |
| IE-062 | P1 | 图片中包含商品主体 | 输入“白底商品图” | 才合成白底；仅去背景时保持透明 | 3.4 |
| IE-063 | P2 | 图片中存在遮挡、缺失或非正面结构 | 提交补全/正面重建类请求 | 记录 reconstruction 标记；不宣称为真实拍摄恢复 | 3.4 |
