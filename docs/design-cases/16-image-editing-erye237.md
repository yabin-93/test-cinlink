# 图像编辑能力 · 测试用例（ERYE-237）

> 需求：云效 `ERYE-237《【全】图像编辑能力新增》`
> 来源章节：3.1 版本与视图 / 3.2 画笔文字形状 / 3.3 图上批注与对话引用 / 3.4 移除背景、AI 擦除、比例 / 3.5 处理状态与导出
> 说明：技能目录中没有“需求转用例”的专用 skill（`yunxiao-defect-sync` 只用于缺陷同步），本文件按现有设计用例规范编写。

## 一、打开与版本（3.1）

| 编号 | 优先级 | 前置/步骤 | 预期 | 来源 |
|---|---|---|---|---|
| IE-001 | P0 | 会话中点击图片卡片 | 打开图像编辑器，加载对应图片 | 3.1 |
| IE-002 | P0 | Agent 指定某张图片“打开编辑器” | 打开同一 document，不落到“最后一张图片” | 3.1 |
| IE-003 | P0 | 打开后检查上下文绑定 | 绑定 conversationId、documentId、assetId、versionId | 3.1 |
| IE-004 | P1 | 查看版本缩略图 | 按派生关系与生成时间排序，编号/文件名/引用绑定确切 versionId | 3.1 |
| IE-005 | P0 | 对同一图片再次生成 | 新结果追加到同一文档，不新建孤立文档 | 3.1 |
| IE-006 | P0 | 从历史版本继续编辑 | 产生分支，不覆盖其后版本 | 3.1 |
| IE-007 | P1 | 生成处理中查看缩略图 | 显示 job 占位，成功前不可导出 | 3.1 |
| IE-008 | P1 | 缩放 100% / 适合窗口 / 平移 | 只改视图，不改分辨率/坐标/导出；批注与笔迹跟随图像 | 3.1 |
| IE-009 | P2 | 窄窗口打开编辑器 | 优先收起项目导航；收起后保留选中版本、草稿与引用 | 3.1 |

|---|---|---|---|---|

| IE-018 | P0 | 绘制线段/箭头/矩形/圆形/三角形/星形 | 记录类型、几何、样式，不只保存截图 | 3.2 |
| IE-019 | P1 | 色板、色相/饱和度、RGB 输入 | 颜色正确应用到当前对象 | 3.2 |
| IE-020 | P1 | 吸管采样 | 取图像与内容层合成结果，排除光标、批注、遮罩、棋盘格 | 3.2 |

| IE-022 | P0 | 画笔橡皮擦局部擦除自由笔迹 | 仅擦本草稿；底图与已扁平化历史不受影响 | 3.2 |

| IE-027 | P0 | 同一消息含“把圈出的内容替换为…” | 进入 AI 编辑，而不是纯绘制 | 3.2 |
| IE-028 | P2 | 将对象设为 guide | 仅作指示，不烘焙进结果 | 3.2 |
| IE-029 | P1 | 生成后尝试继续编辑已融合内容 | 不承诺可编辑原对象；原草稿可从历史恢复 | 3.2 |
