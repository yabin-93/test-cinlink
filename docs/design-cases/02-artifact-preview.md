# 02 产物实时预览

设计页面：`Page2 产物的实时预览` · 画板：`hover 视频区`、`点击进入编辑`、`完成编辑-失焦保存`、`超出字符限制提示`、`更新语音`、`hover 两条之间`、`点击后旋转，完成更新后无提示`。

| ID | 优先级 | 类型 | 用例标题 | 前置条件 | 操作步骤 | 预期结果 | 设计来源 | 可自动化 |
|---|---|---|---|---|---|---|---|---|
| DC-02-001 | P0 | 正常 | 生成完成后进入实时预览 | 任务已完成，有视频产物 | 点击结果卡片中的预览 | 打开实时预览；视频可播放，展示时间轴与字幕 | 首页 → 生成结果 | UI |
| DC-02-002 | P1 | 交互 | hover 视频区显示操作 | 预览已打开 | 鼠标移到视频区 | 显示播放/暂停、音量、全屏等操作；移出后隐藏 | hover 视频区 | UI |
| DC-02-003 | P0 | 交互 | 点击字幕进入编辑 | 视频带字幕 | 点击字幕条目 → 进入编辑态 | 字幕进入可编辑态并聚焦；其他区域不误触发 | click / 点击进入编辑 | UI |
| DC-02-004 | P0 | 状态 | 完成编辑后失焦保存 | 字幕处于编辑态 | 修改文本 → 点击空白处（失焦） | 自动保存修改；再次进入编辑时内容为新值 | 完成编辑-失焦保存 | UI |
| DC-02-005 | P1 | 异常 | 超出字符限制提示 | 字幕处于编辑态 | 输入超过上限的字符 | 出现“超出字符限制提示”，阻止继续输入或保存并给出原因 | 超出字符限制提示 | UI |
| DC-02-006 | P1 | 交互 | 切换说话人后生成音色变化 | 视频含多个说话人 | 切换说话人 → 点击“更新语音” | 生成音色随说话人变化；原始音色保持不变，可切回 | 更新语音 / 说话人可以切换 | UI（待确认） |
| DC-02-007 | P1 | 交互 | 文稿编辑与字幕互不同步 | 已有字幕与文稿 | 在文稿区修改文本 → 观察字幕 | 文稿改动不同步给字幕（设计标注：两者不互通）；切换场景时应用现有改动 | 文稿区交互 / 对文稿的操作不会同步给字幕 | UI |
| DC-02-008 | P2 | 交互 | hover 两条字幕之间显示插入/分割 | 字幕有多条 | 鼠标移到两条字幕之间 | 显示插入/分割操作；点击后可新增一条字幕 | hover 两条之间 | UI |
| DC-02-009 | P2 | 交互 | 编辑完成后旋转再更新无提示 | 字幕编辑完成 | 点击旋转图标 → 完成更新 | 完成后不弹提示，状态静默更新 | 点击后旋转，完成更新后无提示 | UI |
| DC-02-010 | P1 | 展示 | 中英双语两行与单行翻译展示 | 任务含翻译字幕 | 查看字幕区 | 双语场景单条字幕两行展示；单语翻译场景一行展示，不串行 | 两种情况：单个字幕的中英文两行展示、一行字幕的翻译展示 | 人工 |
| DC-02-011 | P2 | 展示 | 字幕时间区间对应原视频时间 | 已打开预览 | 选中任一字幕 | 时间区间为原视频所在时间段，与视频轴一致 | 时间区间是原视频所在的时间段 | UI |
