# 07 视频批注

设计页面：`视频批注` · PRD：`ERYE-131《CinLink 视频批注功能》`（2026-09-08 更新）。
关键画板：`批注`、`批注弹窗`、`批注状态`、`点选/圈选/框选`、`发送后，批注消失`、`添加到对话框效果`、`当第二次批注超过30秒`、`当视频正在加载时`。

> 裁决原则：**以设计稿为准**；PRD 只补充与设计稿不冲突的规则（结构化锚点、两阶段提交、状态机、剪辑映射、异常与兼容）。设计稿中的“点选/圈选/框选 + 物体识别”“默认 5 秒 / 最长 30 秒”“重叠另起一行”均按设计稿纳入 MVP。
