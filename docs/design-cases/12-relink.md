# 12 Relink File

设计页面：`Relink File` · 画板：`image 1`、`image 2`（编辑器与对话中的素材缺失/重链）。

| ID | 优先级 | 类型 | 用例标题 | 前置条件 | 操作步骤 | 预期结果 | 设计来源 | 可自动化 |
|---|---|---|---|---|---|---|---|---|
| DC-12-001 | P0 | 异常 | 素材缺失时展示重链入口 | 工程引用的本地文件被移动或删除 | 打开工程 | 素材卡片显示 Click to relink；时间轴片段标记 File missing；预览提示无法解码 | image 2 | UI |
| DC-12-002 | P0 | 正常 | 重新选择文件完成重链 | 处于缺失状态 | 点击 Click to relink → 选择正确文件 | 素材恢复可预览；时间轴 File missing 消失；可正常导出 | image 2 | UI |
| DC-12-003 | P1 | 异常 | 选错文件时拒绝重链 | 缺失素材 | 选择一个不匹配的文件 | 提示文件不匹配/无法识别，保持缺失状态，可重试 | image 2 | UI（待确认） |
| DC-12-004 | P1 | 交互 | 文件改名或移动后重链 | 文件仍在磁盘但路径变化 | 通过重链选择新路径 | 重链成功，引用关系保留，无需重新剪辑 | image 2 | UI |
| DC-12-005 | P2 | 异常 | 文件已删除的兜底 | 文件已不存在 | 尝试重链 | 提示文件已删除，引导重新上传或忽略该素材 | image 2 | UI |
| DC-12-006 | P1 | 交互 | 对话中的重链建议 | 在会话中发现素材缺失 | 查看 AI 消息 | 展示原因说明与三个入口：文件在另一个路径 / 文件名变了 / 文件已删除 | image 2 | UI |
