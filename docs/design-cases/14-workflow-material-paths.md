# 工作流 × 素材方式 × 发送方式 · 用例矩阵（含单/多工作流）

目标：主功能工作流全部覆盖，并区分 **单工作流** 与 **多工作流** 场景；每个场景都覆盖：

- 素材进入方式：M1 / M2 / M3
- 任务发送方式：S1 直接发提示词 / S2 点击功能卡片

规模：

| 场景 | 数量 | 组合 |
|---|---|---|
| 单工作流 | 8 个 | 8 × 3 × 2 = **48** |
| 多工作流 | 5 类 | 5 × 3 × 2 = **30** |
| 合计 | 13 类 | **78 条** |
| AI 生图卡片（参数） | 5 条 | 分辨率 × 比例的代表组合 |
| AI 视频卡片（参数） | 5 条 | 分辨率 × 比例 × 时长代表组合 |

编号：单工作流 `WF-<n>-M<x>-S<y>`；多工作流 `MW-<n>-M<x>-S<y>`。

|---|---|---|---|

## 二、多工作流场景

| 编号 | 场景 | 示例指令 / 操作 | 关注点 |
|---|---|---|---|
| MW-01 | 串行依赖（先剪后字幕） | 先「长变短」→ 再对产物「生成中文字幕」 | 第二条任务是否引用第一条产物、时长是否继承 |
| MW-02 | 同源并行（字幕 + 翻译） | `给这个视频生成中文字幕` + `翻译成英文` | 两条任务是否共用素材、产物是否串台 |
| MW-03 | 同源并行（增强 + 文字水印） | `增强画质` + `加文字水印 E2E-TEST` | 产物是否叠加、是否互相覆盖 |
| MW-04 | 单句复合意图 | `增强画质并加中文字幕` | 一个 prompt 是否拆成多个子任务、产物是否齐全 |
| MW-05 | 多素材多任务 | 视频 A 生成字幕、视频 B 翻译 | 素材与任务是否一一对应、互不串台 |

> 多工作流的“3 种素材方式”同样按 M1/M2/M3 执行；“2 种发送方式”同样按 S1/S2 执行（S2 允许连续点两张卡片）。

## 三、素材进入方式（M）

| 编号 | 方式 | 做法 |
|---|---|---|
| M1 | 对话框直接上传 | 点「＋」上传视频，不 `@`，直接发送 |
| M2 | 首页项目对话框 @ | 新建项目对话框上传视频，在对话框中 `@` 选中后发送 |
| M3 | 上传后再 @ | 先「＋」上传，再在输入框 `@` 选中后发送 |

## 四、任务发送方式（S）

| 编号 | 方式 | 做法 |
|---|---|---|
| S1 | 直接发送提示词 | 输入框输入指令并发送 |
| S2 | 点击功能卡片 | 卡片分两类：<br>• **S2-a 隐藏提示词**：AI 生图/AI 视频，点卡片后直接提交，前端不展示提示词；<br>• **S2-b 预填提示词**：长变短等剪辑卡片，会把默认提示词写进输入框，并展示参数（如精华时长），需用户确认发送。 |

> S2 说明：不同分组的卡片行为不同。\n> • 「素材与生成」的 AI 生图/AI 视频：隐藏提示词，参数（分辨率/比例/时长）可见；\n> • 「剪辑与优化」的长变短：会把默认提示词写进输入框，并出现「精华时长」参数；\n> 断言时要先确认卡片属于哪一类，不能统一用“输入框为空”或“输入框有文本”。\n> 因此 S2 不能用“输入框文本”做断言，只能看 run 是否创建、路由/产物是否是该卡片的工作流。\n> 一张卡片只承载一个工作流。连续点两张时，第二张的结果卡片会替换第一张；
> 多工作流用 S2 时必须“先完成第一张，再点第二张”，并额外验证第一张的 run/产物是否仍可在历史中取到。

## 六、单条用例骨架

| 阶段 | 操作 | 断言 |
|---|---|---|
| 准备 | 按 M1/M2/M3 送入视频（多素材场景送 2 个） | 素材在会话资产或 `@` 候选中 |
| 发送 | S1 输入指令，或 S2 点击卡片（多工作流可连续两次） | 每次发送都得到 run_id |
| 收敛 | 轮询所有 run | 全部进入 `done`，无 `failed`/卡死 |
| 产物 | 汇总产物 | 单工作流 ≥1；多工作流按场景断言数量与类型 |
| 结构 | 下载校验 | 视频可播放/时长合理；SRT 合法 |
| 隔离 | 多任务/多素材 | 产物不串台、素材引用正确 |
| 账本 | 查余额 | 扣费与任务数一致 |

### 多工作流额外断言

| 场景 | 额外检查 |
|---|---|
| MW-01 | 第二条任务引用第一条产物；字幕时长 ≤ 短视频时长 |
| MW-02 | 两条产物各自独立；中/英文字幕条数接近 |
| MW-03 | 增强产物同时保留水印；或明确只有一条生效 |
| MW-04 | 子任务数量 = 意图数；产物齐全或给出明确失败项 |
| MW-05 | 视频 A 产物只对应 A；B 同理；无交叉引用 |
| S2 取消路径 | 点取消后出现中断弹窗；第一张 run 停止，产物列表不新增该任务结果 |
| 多工作流 + S2 | 卡片直接提交隐藏提示词；输入框不应残留指令；第二张替换结果卡，第一张 run 继续跑完、产物可在产物列表找到；取消必须出现中断弹窗 |

## 八、自动化落地

```ts
const single = [...];   // 8 个工作流
const multi = [...];    // 5 个多工作流场景
const materials = ["M1", "M2", "M3"];
const sends = ["S1", "S2"];

for (const flow of [...single, ...multi])
  for (const m of materials)
    for (const s of sends)
      test(`${flow.id}-${m}-${s}`, async ({ page }) => {
        await enterMaterial(page, m, flow.assets);
        await sendTask(page, s, flow.steps);
        await assertRuns(page, flow);
      });
```

`assertRuns` 需要支持多 run：等全部收敛、汇总产物、检查隔离。

## 九、缺口与已知问题

- 混剪：`CINLINK-MIX-001` 未修复前，WF-07 六条 `fixme`；

## 十、AI 生图卡片（带参数的 S2）

首页「素材与生成」分组里有 AI 生图、AI 视频等卡片；点击 **AI 生图** 后需要先选：

- 分辨率：`1K` / `2K` / `4K`
- 图片比例：`1:1` / `3:4` / `4:3` / `9:16` / `16:9` / `21:9` / `9:21`

### 参数用例

| 编号 | 分辨率 | 比例 | 断言 |
|---|---|---|---|
| IG-01 | 1K | 1:1 | 产物为正方形；边长符合 1K 档 |
| IG-02 | 2K | 9:16 | 产物竖屏；宽高比 ≈ 9:16 |
| IG-03 | 4K | 16:9 | 产物横屏；分辨率达到 4K 档 |
| IG-04 | 2K | 3:4 | 切换比例后重新生成，产物比例随之变化 |
| IG-05 | 默认 | 默认 | 未手动选择时使用默认参数，且参数面板有默认选中态 |

### 断言要点

- 产物实际像素尺寸与所选分辨率档位一致（允许平台侧取整）；
- 宽高比与所选比例一致（允许 ±1px）；
- 切换比例后再次生成，不复用上一次尺寸；
- 参数选择面板在发送前可见、可切换，发送后不残留提示词。

### S2 通用步骤（带参数卡片）

1. 点卡片（AI 生图）；
2. 在参数面板选择分辨率与比例；
3. 点发送；
4. 等待 run 完成，下载产物；
5. 校验像素尺寸与宽高比。
## 十一、AI 视频卡片（带参数的 S2）

首页「素材与生成」分组里的 **AI 视频** 卡片，发送前需要选：

- 分辨率：`720P` / `1080P`
- 视频比例：`16:9` / `9:16` / `1:1`
- 生成时长：`5 秒` / `10 秒`

选完后点发送，提示词由卡片默认生成、前端不展示。

### 参数用例

| 编号 | 分辨率 | 比例 | 时长 | 断言 |
|---|---|---|---|---|
| IV-01 | 720P | 16:9 | 5 秒 | 横屏、720P 档、时长 5±0.5 秒 |
| IV-02 | 1080P | 9:16 | 10 秒 | 竖屏、1080P 档、时长 10±1 秒 |
| IV-03 | 720P | 1:1 | 5 秒 | 正方形、时长 5±0.5 秒 |
| IV-04 | 1080P | 16:9 | 5→10 秒 | 切换时长后重新生成，产物时长随之变化 |
| IV-05 | 默认 | 默认 | 默认 | 不手动改参数时使用默认档，面板有默认选中态 |

### 断言要点

- 产物分辨率与所选档位一致（允许平台取整）；
- 宽高比与所选比例一致；
- 实际时长与所选时长一致（±1 秒）；
- 切换时长后再次生成，不复用上一次时长；
- 参数面板在发送前可见、可切换，发送后不残留提示词。
## 十二、长变短卡片（S2-b：预填提示词 + 精华时长）

「剪辑与优化」分组里的卡片（去口水词、画面增强、长变短、添加水印）点击后表现不同，其中**长变短**已确认：

- 会把默认提示词写进输入框：`把这条长视频剪成适合发布的短视频`
- 出现参数「精华时长」，默认 `3 分钟`
- 用户可改时长后点发送

### 参数用例

| 编号 | 精华时长 | 断言 |
|---|---|---|
| LT-01 | 3 分钟（默认） | 输入框出现默认提示词；产物时长 ≤ 3 分钟 |
| LT-02 | 1 分钟 | 产物时长 ≈ 1 分钟（±10 秒） |
| LT-03 | 5 分钟 | 产物时长 ≈ 5 分钟（±30 秒） |
| LT-04 | 3 分钟 → 1 分钟 | 切换后重新生成，产物时长随之变化 |

### 断言要点

- 点击卡片后输入框应出现默认提示词（区别于 AI 生图/视频的隐藏提示词）；
- 精华时长选择器有默认值，切换后再次生成应使用新值；
- 产物时长与所选精华时长一致（允许平台裁剪误差）；
- 发送后输入框被清空，参数面板关闭。

## 十三、卡片行为分类（S2）

| 分组 | 卡片（action-id） | 提示词 | 参数（默认） |
|---|---|---|---|
| 素材与生成 | 本地素材查找 `local-material` | 隐藏 | 无 |
| 素材与生成 | AI 生图 `image` | 隐藏 | 分辨率（1K/2K/4K，默认 1K）、图片比例（1:1 等，默认 1:1） |
| 素材与生成 | AI 视频 `video` | 隐藏 | 分辨率（720P/1080P/2K/4K，默认 720P）、视频比例（16:9/9:16/1:1/3:4/4:3，默认 16:9）、生成时长（3/5/8/10/12/15 秒，默认 5 秒） |
| 剪辑与优化 | 去口水词 `clean-cut` | 隐藏 | 无 |
| 剪辑与优化 | 画面增强 `enhance` | 隐藏 | 无 |
| 剪辑与优化 | 长变短 `shorten` | **预填**「把这条长视频剪成适合发布的短视频」 | 精华时长（30s/60s/90s/2min/3min，默认 3 分钟） |
| 剪辑与优化 | 添加水印 `watermark` | 隐藏 | 无（点击后可能进入水印配置） |
| 字幕与翻译 | 字幕 `transcribe` | 隐藏 | 视频语言（默认 Auto detect）、目标语言（默认 No translation） |
| 字幕与翻译 | 翻译 `translate` | 隐藏 | 翻译模式（配音/字幕/两者，默认「Dubbing and subtitles」）、视频语言（Auto detect）、目标语言（默认 English） |
| 提炼与再创作 | 总结 `summarize` | 隐藏 | 无 |
| 提炼与再创作 | 缩短 `shorten` | 隐藏 | 无 |
| 提炼与再创作 | 旁白回顾 `narrated-recap` | 隐藏 | 旁白时长（3/10/20 分钟，默认 3 分钟） |

> 已用 staging 实际 DOM 验证：卡片的稳定锚点是 `[data-workspace-action-id="<id>"]`，分类标签是 `[data-workspace-category="material|editing|subtitles|repurpose"]`。
> 目前只有「长变短」会预填提示词；其余卡片提示词隐藏，只展示参数。
