# 05 编辑器默认 TAB 调整

设计页面：`编辑器默认TAB调整` · 画板：`剪辑`、`素材`、`配音`、`字幕`、`水印`、`属性`、`编辑页-剪辑`、`编辑页-素材`、`切换侧边栏`。

| ID | 优先级 | 类型 | 用例标题 | 前置条件 | 操作步骤 | 预期结果 | 设计来源 | 可自动化 |
|---|---|---|---|---|---|---|---|---|
| DC-05-001 | P0 | 正常 | 编辑器默认 TAB 为剪辑 | 打开编辑器 | 观察默认选中 TAB | 默认选中“剪辑”，展示剪辑面板而非素材 | 编辑页-剪辑 | UI |
| DC-05-002 | P1 | 正常 | 从素材入口进入时落在素材 TAB | 在素材区点击某个素材打开编辑器 | 观察选中 TAB | 落在“素材”TAB，且定位到该素材 | 编辑页-素材 | UI |
| DC-05-003 | P1 | 交互 | 切换各 TAB 保持状态 | 编辑器已打开 | 依次点击 剪辑/素材/配音/字幕/水印/属性 | 面板正确切换；播放进度与当前选中对象保留 | 剪辑 / 素材 / 配音 / 字幕 / 水印 / 属性 | UI |
| DC-05-004 | P1 | 交互 | 配音 TAB 可用 | 视频含音轨 | 切到“配音” | 展示配音/音色相关操作；无音轨时提示不支持 | 配音 | UI |
| DC-05-005 | P1 | 交互 | 字幕 TAB 可用 | 视频含字幕 | 切到“字幕” | 展示字幕列表与样式设置；无字幕时展示空态 | 字幕 | UI |
| DC-05-006 | P1 | 交互 | 水印 TAB 可用 | 编辑器已打开 | 切到“水印” | 展示文字/图片水印设置，修改后预览实时更新 | 水印 | UI |
| DC-05-007 | P2 | 交互 | 属性 TAB 随选中对象变化 | 编辑器已打开 | 选中不同对象 → 切到“属性” | 属性面板展示当前对象属性；未选中时展示默认态 | 属性 | UI |
| DC-05-008 | P1 | 交互 | 侧边栏折叠时 TAB 行为 | 编辑器已打开 | 折叠侧边栏 → 展开 | 折叠前选中的 TAB 在展开后保持 | 切换侧边栏 | UI |
