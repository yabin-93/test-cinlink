## 公共前置与操作

1. 每轮使用一个专用测试项目，各例新建独立会话并记录用例号；不必每例新建项目（用户2026-11-09最新要求）。仅导入本例授权素材。上传后先完成一次必要处理建立图片工程；直接生成的图自动建立工程。准备任务、正式任务及费用分开记录。
2. 使用用户指定的生成人像`output/imagegen/portrait-annotation-test-20261109.png`（实际1254×1254），记录实际已保存基线V1的文件、尺寸、画布及历史。检查无其他人同时操作、无在途任务、无其他批注或待发送引用。每例独立准备，不默认使用上一例输出。
3. 在图内明确位置点击“标注”，点击批注编号打开浮层，填写完整提示词；需要对象选择时核对识别目标，必要时手动选择/命名。不得将识别名当作定位成功的唯一证据。
4. 使用浮层实际提供的“添加到对话”（辅助功能名称“添加到待引用项”）或等效按钮携带批注位置和正文；若只是形成待发送引用，再点击页面发送。若按钮直接受理任务，不再重复发送。记录实际按钮名称与步骤，工具缺失据实际行为记录，不虚构按钮。发送前核对正文及引用，发送后核对已发送消息；全局文字必须出现在消息中，不能仅凭输入框中可见就认定提交成功。自动化优先点击输入框并粘贴，避免仅设置显示值而未触发实际输入。
5. 内容型用例等待终态，检查真实输出、画布、历史、重开保存和可下载文件。生成失败记录错误及草稿状态；已受理请求不自动重发。人工对照位置/数量/保留主体，不能仅凭“已完成”文字通过。
6. 新增对象允许局部接缝与合理阴影变化；除明确指定的修改外，不得遮挡人物、明显改变人物面貌/身体/服装/黄色手包或改变画幅。生成内容不要求逐像素一致。执行前将目标位置截图圈定并登记归一化坐标及允许修改区域；这些是测试定位记录，不是向模型上传额外蒙版的默认要求。
