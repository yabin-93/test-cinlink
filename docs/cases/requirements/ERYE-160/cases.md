# 计费逻辑更新 · 用例（ERYE-160）

> 需求：云效 `ERYE-160《计费逻辑更新》`（CinLink 国际版各功能积分计费 PRD v1.0）
> 覆盖：价格目录、视频/图片/转录/Token/TTS 计费、本地免费、预估冻结结算、用户展示、账本风控、一致性

## 执行准备

本文件采用[统一编写规范](../../authoring-guide.md)。测试前登记获准环境、账号、真实价格目录/任务/账本入口、对应操作和计价版本。只准备本例所需素材与余额；计量样本按独立时长、UTF-8字节或原始Token usage核准。具体数值、公式和单位以各条原预期为准，不能从被测返回反推标准。

真实接口专项使用已实现的schema及获准读权限，不猜端点；供应商响应、时钟、价格发布、故障、管理员和区域/会员对照均在具备相应控制的隔离环境执行，不改共享生产配置。无真实夹具或权限时仅记录该分支缺少前置，不能用模拟页面成功代替结算。每组参数独立执行，单组失败不吞并其余组。

用例正文仅维护设计；实际结论、脚本运行状态和证据在独立报告维护。文案整理不改原执行状态或自动化实现。
