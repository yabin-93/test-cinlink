# 图像编辑能力测试用例 ERYE-237

## 共用规则

1. 按[统一编写规范](../../authoring-guide.md)、[执行规则](execution-guide.md)及[数据规格](test-data.md)准备本条对象。上传图先完成一次实际处理才建工程，提示词生图自动建工程；优先复用已核对工程，不为每例重复制作。
2. I1/I2/I3为本例独立登记图片，V1为本例真实保存基线，不默认等于上传原图；V2/V3为同工程实际完成版本，S0原文件保留。Q等锚点以独立源坐标登记；缩放后需按真实变换定位。
3. UI点击真实工具/浮层；Agent使用本条完整指令并将名称、版本、位置占位符换成实际值。UI、Agent配对和Technical分别核验，不能相互代表；纯切工具或本地绘制不擅自生成。
4. 页面文字使用当前默认字号及实际显示大小，不用画笔粗细替代文字字号。Agent原明确字号参数及技术分支保留；红线参考不要求烘焙到成品，明确内容文字按原指令保留。
5. 单请求只处理一张图片，同图可有多批注；多图按原先后逐图独立提交，不用前轮成品冒充另一图原源。批注删除入口为其浮层输入框右上垃圾桶，移除待发引用与删除批注分别验证。
6. 点击工具若已受理，不追加发送；未知结果先回读。每个合法参数行只发一次，等真实终态并核文件/画布；拒绝行检查原文和引用保持。长文本按链接固定全文复制并独立计数，不用摘要代替原文。
7. 技术矩阵、UI/Agent配对、源单位/像素/账务证据均保留原范围。缺某技术条件只阻塞相关分支，不降低必测要求；合并编号仅追溯原入口，不另创建重复执行。
8. 正文只维护设计，实际结果、报告、云效状态及截图已在独立状态/历史记录维护。分支与参数行分别记录，不把单分支通过算整例完整通过。
