## 共用前置与执行方式

1. 正式环境复用已有测试窗口，按本轮授权核对页面实际选中的会话、工程ID、名称及保存内容，不能只按同名选择。当前为[英文30S.mp4](https://app.cinlink.ai/c/8bd67283-c5ae-49d8-9789-78413b3bfa8c)、工程`b34e8f29-25ac-4dc0-968f-76aabdd20e13`；页面验证后版本22、完整内容已恢复到测试前版本8。B01/B02历史工程是a4c860bc…，不得混用。[登记基线及接续](user-project-baseline-20261106.md)保留各轮区别，不能覆盖用户后续修改。
2. 登记基线：版本2；一段视频源0～30.6306秒、时间线起点0、29.97fps；原声静音；一条未静音的独立旁白，音源0～28.975193秒、时间线起点0；13条可编辑英文字幕，属于译文通道。没有BGM、逐句配音条目及独立水印对象。本批只使用这些实际对象，不要求先补齐完整B0夹具。
3. 各例从自己的已核对基线开始。表中时间、文字以该基线为准；若用户已有改动，先更新本例目标和预期再发送。字幕基准：第2条3.26～3.52秒`real?`；第3条3.70～6.66秒`I recorded this entire clip without looking into the lens`；第13条27.54～28.00秒`the lens.`；28.20～29.20秒无可编辑字幕。
4. Agent入口：记录前置和截图 → **只发送表内这一条提示词一次** → 有澄清则填写真实目标并继续，保留填写值和截图 → 等原任务结束 → 核对页面和实际保存内容 → 刷新同一工程核对。记录run、终态、保存版本及真实结果；任务done或助手说成功均不能单独判Passed。若页面手动操作成功而Agent失败，分别记录入口，不能覆盖Agent结果。
5. 页面入口项按表内操作执行，不额外让Agent做一遍。检查、等待保存和刷新是验收步骤，不再添加新的业务编辑。既有真实接口回读可辅助核验，不以需求中拟定的接口名、字段或错误码作为通过条件。
6. 每项修改后记录系统自然发生的关联变化，不额外发送字幕/音频同步指令来掩盖结果。只裁单个对象的检查不替代自动联动检查；非目标对象发生意外丢失或改文也要记录。字幕预览需区分可编辑字幕与视频像素中的烧录字幕。
7. 各例之间通过现有撤销入口恢复本次修改，并核对内容回到该例前置；版本号可以正常递增。**不能直接保存旧JSON来恢复项目，也不自动克隆替代用户工程。** 撤销尚未验证时先从可恢复的小改动验证B20/B21；删除等操作后置。恢复失败则停止依赖该基线的后续项，不能继续套用旧目标。
8. 当前没有确认的毫秒阈值。按页面实际时间精度、帧率及真实保存结果登记裁剪/分割边界；发现取整差异记录请求值与实际值，不擅自设容差。声音按可听变化、无误静音、无意外截断等可观察问题验收。

以下均为基础优先执行项。来源列指原用例的能力范围；注明“分支/变体”的条目只覆盖所列单动作，完整要求仍在原条目。

## 执行顺序与组合用例准入

先做B01；首次有成功的小改动后优先验证B20/B21，确认能安全恢复，再分别跑字幕、旁白、视频单项。B03已有失败，不自动重试；修复后再定向复测。删除/复制后置，B23/B24在恢复完整基线后执行。需要静音前置的B16及成功保存前置的B20～B22单独记录准备情况，不能拿不满足的前置直接执行。

某项失败时停止该项后续叠加编辑，保存真实失败截图、提示词、补槽值、run及前后内容，定位失败工具或可观察的保存/预览差异。其他独立项是否继续按用户指定范围执行；同一失败不能使未跑项目自动变为Failed，也不能在错误基线上继续。

后续组合按涉及能力放行：视频裁剪＋字幕/旁白同步，需对应视频裁剪、字幕文字/时间及旁白裁剪单项先通过；裁剪＋改字幕＋调音量，需裁剪、B07、B14先通过；连续多轮编辑需相应基础编辑、B20/B21及B22通过。基础通过后仍必须另跑[013/014联动](cases.md#剪辑内容与字幕配音同步)、[042等复合任务](cases.md#复合修改撤销与并发)，检查一次指令的执行顺序、自动同步和失败结果，不能由单项成绩直接推导。

本清单暂不纳入BGM、水印、双语隔离、逐句配音实体、多素材重排、并发和故障注入；这些仍保留在原用例，按各自真实前置后续执行。本清单也不代替工作流生成能力用例。
