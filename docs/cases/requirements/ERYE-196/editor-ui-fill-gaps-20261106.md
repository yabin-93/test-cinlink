## 需求范围与页面观察

- 图片水印：上传、预览、尺寸、透明度、位置、时间范围、替换、删除。
- BGM：真实音频导入并加入背景轨；音量、静音、裁剪、移动、删除与其他音轨隔离。
- 逐句配音：选定一句，单句生成、预览、改文和删除音频；与独立旁白区分。
- 双语字幕：通过真实导入界面准备第二个中文字幕文件，验证与当前英文文件的改文隔离；实际源/译角色按页面记录，不把“其他”冒充原文。
- 补充字幕文本边界；保存、刷新和撤销恢复贯穿每项。

实际正式环境配音面板提供逐句文本、语言和“生成配音／全部生成13句”；本轮只选一句，不点击全量生成。水印界面提示PNG/JPG/SVG、最大10MB。界面标签可能与本地源码不同，以实际DOM为准。没有提供新设计稿，不由代码中的拟定接口名推断页面通过。
