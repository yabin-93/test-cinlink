## 前置、步骤和验收规则

复用当前正式环境Chrome及用户工程“英文30S.mp4”，工程`b34e8f29-25ac-4dc0-968f-76aabdd20e13`，[会话](https://app.cinlink.ai/c/8bd67283-c5ae-49d8-9789-78413b3bfa8c)。起始版本22，完整内容与首批恢复结果一致：唯一30.6306秒视频、13条英文译文字幕、28.975193秒独立旁白、原声静音、无水印/BGM/逐句配音实体。

每项执行：核对工程身份和前置 → 只做表内一个业务操作 → 核对页面及实际保存结果 → 刷新核对 → 通过页面撤销恢复完整前置并再刷新。版本允许自然递增。恢复失败立即停止依赖该基线的编辑。接口只读回查；不直接写旧JSON恢复，不切换或克隆工程，不发送Agent对话。拒绝无效输入的项目核对错误提示、内容不变及没有错误写入；不能把正确拦截当成产品失败。

样式、音频参数与时间线状态检查，不单独证明听感、导出成片或完整剪辑同步通过。无毫秒阈值，拖动记录实际边界；页面可编辑字幕与原视频像素字幕分开判断。执行序号仅用于本批证据追踪；定位/断言错误单列诊断，不计产品缺陷。
