更新：2026-11-05。配合[134条用例](cases.md)及[统一业务验收口径](../../editor-business-acceptance.md)。本次只优化文档；001/003既有Passed、002/004不适用保留，005因旧引用前置撤销Blocked改为Not Run，未重跑。历史证据见[本次状态说明](business-acceptance-update-20261105.md)。

## 通用前置 P

1. 登记实际平台、账号、当前页面和本例工程；用专用测试副本，只准备本例要检查的对象。只读/单条改文不要求同时制备配音、BGM、水印等完整B0。
2. 记录实际工程名称/链接、字幕原文/时间、画面/声音/样式和文件；真实接口已有的标识、版本、参数仅作定位证据，不要求拟定字段名或类型。
3. 使用已有目标选择方式，或在完整提示词里写清工程、素材、字幕起止时间及原文。别名替换成实际值；不强制引用标签。遇澄清按本例填写并继续，答复前先核对是否有错误修改。
4. 独立原始素材、文字/时间/声音金标及用户指令决定期望。真实返回须与这些标准对照，不能把实际值直接当期望；效果需播放、听审或检查文件，保存后刷新/重开确认。
5. 请求发出后断连不能视为未保存；先重开工程/原任务查真实结果再继续。只改用例不增加业务执行通过数。

## K 真实页面和接口记录

K仅记录当前实际入口、页面操作、已有真实请求、实际参数范围和业务结果，不再表示等待研发冻结PRD接口。接口专项必须先有页面发出的请求或当前已实现服务入口，再构造对照数据；不要按需求拼端点/字段/错误码。

保存成功用真实内容刷新核对；任务完成用对应文件/字幕/声音核对。当前没有拟定内部接口不构成页面失败；已确认的业务功能缺失仍记未实现，不能自动排除。未公布数值限制仅记录业务边界，不套需求建议值。

## F 故障与竞争前置操作

使用本例可复现真实失败、断网/恢复、关闭重开、双标签保存、接近完成取消及迟到结果。无需数据库、投递表、租约、内部锁或专用后端注入点；不能复现则记对应分支未覆盖及原因，不故障共享服务、不修改云端代码。

前端响应模拟只证明展示，不计真实保存/取消/计费通过。响应未知时，重新读取可能得到完整旧内容或完整新内容，应按实际接收情况核对，不武断要求服务端回滚。

## 素材与独立基线

| 数据 | 准备规格与业务标准 |
|---|---|
| A/B | A20秒1920×1080、30fps、H.264/AAC；四段画面/源时间可辨，英语对白及声音金标独立记录。B10秒内容和声音明显不同。精确剪辑用独立帧/时间/声音金标 |
| C1/C2 | 原文Welcome/Second caption、译文欢迎/第二条字幕，4～6秒/10～12秒；用户现有工程则记录其真实文字/时间，不用标准别名替代实际目标 |
| 配音D1/D2、BGM | 两句独立配音与原声/背景音乐可区分；BGM20秒初始0dB，另有-3/-6dB变体；预听并记录剪辑后应保留的内容 |
| W_TEXT/W_IMG | 文字E196-A及可辨识图片水印，logo-A蓝A、logo-B红B；按页面记录位置/时段/透明度及实际支持格式 |
| BTIME/BPERF | 29.97fps及可变帧率源带独立同步标记；大工程1小时、200片段/5000字幕/4音轨，另备1000片段集。性能阈值只用当前已确认业务标准 |
| B0 | 按本例所需部分取A、C1/C2、配音、BGM、水印；核心三项需A片段、保留区间C1及BGM齐备。PA/PB相互独立且内容可辨 |
| BAPP/BSEG | A后接B，总30秒；或A在5秒、10秒分成三段，总20秒。检查实际画面/声音和关联内容，不要求内部ID分配 |
| BCROSS | 原1～3秒跨边界句子、0～1秒完全删除句子；人工词句/声音金标可判断裁头2秒后内容，不要求接口暴露逐字对象 |
| BBURN | 画面有烧录文字但没有可编辑字幕；重新识别不等于直接改掉烧录文字 |
| BLEGACY | 真实旧客户端创建的工程，保留画面、时长、顺序、字幕、声音、水印及旧导出参照；不用手写拟定JSON冒充迁移样本 |
