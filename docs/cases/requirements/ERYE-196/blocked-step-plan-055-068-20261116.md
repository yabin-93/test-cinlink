## ERYE196-055：先验证真实未保存输入，再测试远端冲突

原卡点：输入文字但不按回车、保持焦点，切到独立页面刷新后已读到同文。该入口自动保存，焦点不是草稿判据。

| 步骤 | 操作 | 继续条件/证据 |
|---|---|---|
| A 基线 | 同账号T1/T2打开同工程，记录C1原文、时间和保存状态，两页刷新确认一致 | 留存基线；只准备相关字幕，无需全套B0 |
| B 草稿窗口 | 通过浏览器当前可用的控制，只延迟T1实际字幕保存请求，保留远端同步；T1输入“本机草稿未提交”，T2独立刷新只读核对 | T1有待保存输入，T2仍为基线；留存输入、真实请求状态及T2读值。不只凭一次旧值或无回车认定未保存 |
| C 远端写入 | T2改C1为“055云端新文”，确认保存并刷新核对 | 必须证实云端新文已保存，不用聊天完成代替；T1本机输入仍有记录 |
| D 事件/冲突 | 观察T1远端通知及输入；恢复被延迟的保存通道并观察处理 | 原输入不能无提示消失；不能无用户确认静默覆盖远端新文。记录延迟请求是否真正发出、是否已被受理；未知结果先查询，不额外点击重试 |
| E 用户选择 | 使用当前实际提供的保留、复制、查看最新或重新应用入口；如重新应用，必须明确选择后执行 | 选择前远端新文不被静默覆盖；选择后两页刷新一致。入口需求明确而实际缺失则记录Failed，不改写成不适用 |
| F 清理 | 先保存证据及本机文字副本，确认真实云端结果，恢复T1网络设置 | 仅恢复自有测试修改，不覆盖其他编辑；无未确认的在途请求 |

能力限制：不虚构请求地址、内部字段或延迟接口。如果当前浏览器无法仅延迟保存并保留同步，或待保存窗口仍无法成立，B记Blocked，C～E记“依赖B未执行”，并明确缺少的控制条件。全站Offline只适合作为独立恢复观察，不替代本例在线远端更新保护的通过依据。也不以Agent输入框草稿替代字幕输入草稿。若已形成真实输入却被抹掉、或需求明确的保护功能缺失，按证据判Failed；仅无法构造测试窗口仍是Blocked。

## ERYE196-068：先确认第二账号，再验证同一浏览器切换隔离

原卡点：Chrome和Safari均为U1，多浏览器可用不等于有第二账号。需要获准的U2且无PA权限。

| 步骤 | 操作 | 继续条件/证据 |
|---|---|---|
| A 账号/权限 | 隔离浏览器登录已获准U2，核对与U1不同；直接打开PA链接验证无权访问 | 只记账号别名和权限结果，不记凭据。U2若可访问则换用无共享授权的自有工程，不删除别人的权限。缺U2时A阻塞，不能用匿名页替代 |
| B U1准备 | 主浏览器U1打开PA，记录独特字幕/媒体和会话链接，输入“068-U1-未发送草稿”但不发送；U1另一个对照浏览器保持同工程 | 确认输入未发成任务；截图记录草稿和可辨识内容。需要时复用已有工程/会话，无须每例新建项目 |
| C 同环境换账号 | 主浏览器用页面退出U1并登录U2，核对实际身份；不先清站点数据、不用全新配置替代切换 | 登录由用户处理；账号确认为U2后再继续，保留能暴露旧缓存的同一浏览器环境 |
| D 缓存/后退/直链 | 检查会话列表、输入框、页面后退、刷新和PA直链，尝试从实际入口恢复草稿 | 不显示U1字幕、媒体和草稿，PA无权访问；没有恢复入口则核对页面不出现U1草稿，不虚构按钮 |
| E 旧订阅 | U1对照浏览器将一条自有字幕保存为“068-U1-订阅隔离标记”，确认保存；观察主浏览器U2 | U2不能收到或显示该工程事件/新内容。仅双浏览器隔离不足以证明主浏览器切换后的旧订阅清理 |
| F 回归/清理 | 主浏览器返回U1，核对PA可读取、U2期间没有修改；按备份还原本例标记并清理自有未发送草稿 | 不强制要求U1退出后草稿仍存在，退出清理符合安全目标；不得通过强行恢复旧草稿验证 |

A缺失时只记录已完成的U1准备和缺项，不重复退出登录；D/E观察到泄露或越权则立即记录Failed并停止进一步写入。缺第二账号是环境阻塞，不能优化掉权限隔离目标，也不因无法测试就认定产品失败。

## 状态口径

各步骤分别记录完成/阻塞/未执行、真实页面证据和实际值；只要核心验收分支未执行，整例不标Passed。新版尚未重跑，不覆盖历史Blocked或变更汇总；涉及账号/保存状态的测试仍需Chrome有头实际执行后立即更新文档及脚本实现状态。
