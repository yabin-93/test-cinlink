- 被测编辑、查询、撤销与重做均由当前编辑器自然语言发起；146/147明确安排的手动编辑是被测历史交替的一部分。其余页面操作只用于准备、查看、试听、刷新和核对。

- 每例登记独立S0保存检查点，可在同一专用项目使用多个会话，也可在专用母版逐例恢复并核验S0后继续。不得沿用前例已修改结果；正式撤销只指向本例已成功的编辑，不撤销未知旧历史。152/153仍按各条准备真实多会话/工程关系。先登记会话、工程、字幕文字/时间/样式、相关片段及音轨，再开始本例。
- 每轮记录原提示词、真实回复、S0/S1差异及截图，核对非目标对象。撤销前必须证明对应编辑成功；前步失败仅阻塞有依赖的后步，不对未知历史盲目撤销。不能用反向改文或重新导入成片冒充撤销/可编辑工程。
- 每例最后保存并刷新/重开核对最终文字、时间、片段、样式、音量与源素材保持；涉及声音同时核对轨道值及试听。撤销/重做默认在刷新前完成，不额外强制跨刷新保留Redo。不要求导出，不验证扣费账单、内部字段或调用次数。
- 保存或真实目标前置缺失为具体步骤Blocked；仅未执行仍为Not Run。满足前置但需求内业务动作缺失或结果错误为Failed；支持范围外的增强能力不编造成硬需求，记录澄清/不支持说明与已验证范围。

定位原文和时间可按真实素材一一映射并记录，不能照抄与当前工程不符的4～6秒等示例。实际被测参数不变：例如140/141的命中边界、148的62～64秒、149的500毫秒和158的100%/50%/40%不能随定位替换。原稿中的更多非目标字幕保留并核对，不通过删除无关数据降低保护范围。
