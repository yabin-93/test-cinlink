# ERYE-206 业务验收前置与数据

更新：2026-11-05。适用[67条用例](cases.md)和[统一业务验收口径](../../editor-business-acceptance.md)，本次没有新增执行，全部Not Run。

## 通用前置 P

1. 登记实际平台、账号、当前页面和本例工程；用专用测试副本，只准备本例要检查的对象。只读/单条改文不要求同时制备配音、BGM、水印等完整B0。
2. 记录实际工程名称/链接、字幕原文/时间、画面/声音/样式和文件；真实接口已有的标识、版本、参数仅作定位证据，不要求拟定字段名或类型。
3. 使用已有目标选择方式，或在完整提示词里写清工程、素材、字幕起止时间及原文。别名替换成实际值；不强制引用标签。遇澄清按本例填写并继续，答复前先核对是否有错误修改。
4. 独立原始素材、文字/时间/声音金标及用户指令决定期望。真实返回须与这些标准对照，不能把实际值直接当期望；效果需播放、听审或检查文件，保存后刷新/重开确认。
5. 请求发出后断连不能视为未保存；先重开工程/原任务查真实结果再继续。只改用例不增加业务执行通过数。

## K 真实页面和接口记录

K仅记录当前实际入口、页面操作、已有真实请求、实际参数范围和业务结果，不再表示等待研发冻结PRD接口。接口专项必须先有页面发出的请求或当前已实现服务入口，再构造对照数据；不要按需求拼端点/字段/错误码。

保存成功用真实内容刷新核对；任务完成用对应文件/字幕/声音核对。当前没有拟定内部接口不构成页面失败；已确认的业务功能缺失仍记未实现，不能自动排除。未公布数值限制仅记录业务边界，不套需求建议值。

## F 故障与竞争前置操作

使用本例可复现真实失败、断网/恢复、关闭重开、双标签保存、接近完成取消及迟到结果。无需数据库、投递表、租约、内部锁或专用后端注入点；不能复现则记对应分支未覆盖及原因，不故障共享服务、不修改云端代码。

前端响应模拟只证明展示，不计真实保存/取消/计费通过。响应未知时，重新读取可能得到完整旧内容或完整新内容，应按实际接收情况核对，不武断要求服务端回滚。

## 会话、工程及样式基线

- C0为空会话；P为会话C关联已保存PA；PAB为C关联PA/PB。PA来自A20秒，PB来自内容/声音不同的B10秒；素材金标复用[196](../ERYE-196/test-data.md)。侧栏容器、可编辑工程、任务、导出文件分别辨识。
- 样式例PA原文字幕40/白色，B为新上传素材；已确认业务默认放大10%时得到44/黄色。另备PA独有文字“仅A”、时码、剪辑、配音及水印，检查B只继承明确视觉样式。
- PT有独立原文/译文字幕和配音。首次译制的评论业务“原文关/译文开”，与用户手动“两语都开”分别准备，不能把两字幕语言解释成两声音音轨。
- U1/U2用于独立权限对照；同名不同内容、跨会话继续、删除/移除和迟到结果用专用可恢复数据，不把无关完整B0当门槛。

## S11 ElevenLabs真实字幕回归

准备脱敏真实返回文件/响应及独立人工逐条金标：原字节SHA、语言、起止时间、全文和总条数。自制LF/CRLF、UTF-8/BOM、多行及损坏时间行仅补边界，不能代替真实供应商样本。

经当前实际接收/导入入口处理，在页面、保存重开及实际SRT导出核对条数/文字/时间；异常不能部分覆盖旧字幕或假报成功。单语文件不能复制成两语言；不要求解析器内部字段。

## 证据与适用范围

记录工程数量、实际源/目标、完整指令、候选/选择、真实响应、样式/字幕/声音、任务和截图。未知创建结果先查原工程，不另建补救。任务或尝试标识是否复用只记录真实关系，不以是否复用判定；目标、内容、不重复制作/收费才是标准。

期限/数量/性能只按当前已公开业务规则；未公开仅记录条件，不按拟定解析令牌或内部缓存期限失败。底层同业务复用[196](../ERYE-196/cases.md)，导航复用[210](../ERYE-210/cases.md)，[联合页](../../editor-linked-196-206-210.md)不重复计数。
