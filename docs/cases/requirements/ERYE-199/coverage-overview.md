## 视频、音频片段的分割与拖拽

在各卡片产生的适用轨道组合中，分别检查以下操作：

| 操作对象 | 检查重点 |
|---|---|
| 视频片段分割 | 目标源范围连续、总时长正确；默认关联BGM同切点分割，字幕/原声/译声及独立音频保持 |
| 视频片段拖拽 | 主体平移、左右裁剪及跨视频轨；关联BGM按确认规则同步，其他片段不误移 |
| 音频片段分割 | 对独立音频、BGM、原音、译音分别识别目标，核对分割位置、声音连续性和时长，没有新增重复声音 |
| 音频片段拖拽 | 分角色检查主体平移、左右裁剪及跨音频轨；原生BGM操作反向带动视频，原声/译声/独立音频不带动视频 |

操作前先确认选中的轨道和片段；完成后检查撤销重做、刷新重开及导出保持。跨轨拖放按当前页面实际支持的入口另列场景，不预设能够把视频放入音频轨。

既有002/005/011/012/017等仅提供部分检查。现已补齐ERYE199-083～102的各角色操作矩阵，105～108补双向关联和六类组合隔离；每个适用卡片/角色/左右边缘须单独留结果。既有用例中的旧关联假设不能覆盖用户本轮确认的“仅视频/BGM联动”，未改旧结果或宣称专项已执行。

## 字幕、视频及多种音频同时存在的情况

用户强调的完整组合是：**同一工程同时包含字幕、视频、独立音频、BGM、原音和译音**。ERYE199-079/080在原生译配五轨中另加独立旁白/音效；双语模式不额外增加原文字幕轨。页面可能把译声称为“配音”、BGM称为“背景音乐”，须按实际来源核对身份。

| 内容用途 | 重点检查 |
|---|---|
| 视频 | 选中、分割、裁剪或移动的是指定片段，画面来源正确 |
| 字幕 | 原文/译文对应正确，文字、时码和显示状态不串改 |
| 独立音频 | 额外旁白或音效身份明确，不被当作原音、译音或BGM处理 |
| BGM | 原生BGM与视频双向关联，平移/裁剪/分割同步；独立导入音乐不冒充该角色 |
| 原音 | 源身份及启用/静音符合基线；默认不跟随视频/BGM时间编辑 |
| 译音 | 对应指定语言和配音句，时间正确，不误替换或重复叠加旧声音 |

完整组合需要逐项覆盖：

1. **目标隔离**：分别选中并编辑每类内容，核对其他轨及同类非目标片段保持。
2. **联动范围**：用户确认视频/BGM双向平移、裁剪、分割联动；字幕、原声、译声及独立音频保持原位置。不据此推导变速或音量也强关联。
3. **声音与画面**：按用例设定核对原音、译音、BGM、独立音频的启用及音量组合，检查误静音、重复叠音、错句和音画错位。
4. **多轨操作与恢复**：轨道超出可视区域时仍能准确选择目标；核对撤销重做、刷新重开及实际导出后的画面、字幕和混音。

既有ERYE199-001/011/013/019/020/042/045/047/052及[ERYE210-047/048/054](../ERYE-210/cases.md)可提供部分素材/思路；完整六类组合及各角色操作以主用例第十五章为准。48条新增设计均Not Run，自动化PLAN；现行总142条，原62条执行记录保持。
