## ERYE210-046

**已清理工程重新分析不重复移除**

**前置操作**：新工程20秒原片及8条英语SRT，无旧分析；阈值0.8秒，只选择真实停顿候选。

**提示词/输入**：首次分析参数为最短停顿0.8秒、仅停顿类别。清理后的页面若无重新分析按钮，使用现有会话入口明确只分析。按本轮实际新工程和保留源区间的完整输入为：

> 只分析当前工程已保留的片段（共{保留时长}秒，源区间{实际保留区间}）。识别口水词及至少0.8秒的停顿，列出候选后等待审核。保留当前时间线和全部内容，不应用候选或生成成片。

如复核这一历史二次分析分支，填入本轮首次清理后的保留时长和源区间。现行 046 使用 v3 同页恢复用例。

**步骤**：

1. 明确分析，记录真实停顿候选及原视频源区间。

2. 一次应用当前停顿组，等待保存并记录实际删除源区间和清理后字幕/原声。

3. 对同一已清理工程明确重新分析，保留同样筛选参数。当前文稿没有重分析按钮时，通过现有会话发送上面的完整只分析指令；若工具明确不支持限定保留片段，记实际能力阻塞，不调用全20秒分析替代。

4. 核对重新分析没有自动再次剪辑，候选不重复指向已删除源区间；若有合法剩余候选，保持未应用并记录。

5. 切页并重开，核对清理后时长及字幕/原声保持。

**预期结果**：二次分析基于当前结果；不能把已删除范围再次作为可移除对象，不因分析重复剪辑。不开固定候选数或算法字段硬条件。

**去重**：增加二次分析入口及已删除源时段保护，区别于031仅刷新不重复应用。

**脚本**：tests/editor/erye210-current-five.spec.ts；定义更新时Not Run，实际状态见执行报告。
