# 编辑器默认入口测试用例

按[统一编写规范](../../authoring-guide.md)、[业务验收口径](../../editor-business-acceptance.md)和[前置与数据](test-data.md)执行。主页面基准为Media→Scripts→Captions→Voiceover→Watermark，不增加第六入口，不用旧六TAB或未确认设计替代当前基准。

## 共用规则

1. 只准备本条工程及对象。PA/PB为内容可区分的独立工程A/B；字幕C1/C2按实际原文和时间登记；文稿、字幕和音轨分别可辨。U1/U2必须为不同获准账号。
2. O指已登记真实控件及其范围，F指本例隔离延迟/故障控制。使用实际按钮或已发布真实入口，不猜内部锁、缓存键或提交协议；Q210-08等待确认规范继续保留原适用边界。
3. PCLEAN为独立听审金标的清理工程，K1为源9～10秒可删区间；CWORD为8～12秒跨边界词句，CNOWORD无可用逐词结果但有原音/句子标准；两句8～9、10～12秒场景按本条明确值优先。完整金标与数据分别准备，不能用本次候选自证。
4. 指令按本条完整发送，真实澄清继续填写；自然语言编辑不以点击按钮代替。UI草稿、清理、撤销等原定手动操作保留，切页不自动生成或应用未发内容。
5. 多参数、账号/设备、失败恢复分支分别核验，实际保存重开及文件/声音按本条预期检查。原执行状态、脚本及证据独立维护；正文不记执行流水，历史记录完整归档。
