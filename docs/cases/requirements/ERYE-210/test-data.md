## 通用前置 P

1. 登记实际平台、账号、当前页面和本例工程；用专用测试副本，只准备本例要检查的对象。只读/单条改文不要求同时制备配音、BGM、水印等完整B0。
2. 记录实际工程名称/链接、字幕原文/时间、画面/声音/样式和文件；真实接口已有的标识、版本、参数仅作定位证据，不要求拟定字段名或类型。
3. 使用已有目标选择方式，或在完整提示词里写清工程、素材、字幕起止时间及原文。别名替换成实际值；不强制引用标签。遇澄清按本例填写并继续，答复前先核对是否有错误修改。
4. 独立原始素材、文字/时间/声音金标及用户指令决定期望。真实返回须与这些标准对照，不能把实际值直接当期望；效果需播放、听审或检查文件，保存后刷新/重开确认。
5. 请求发出后断连不能视为未保存；先重开工程/原任务查真实结果再继续。只改用例不增加业务执行通过数。

## K 真实页面和接口记录

K仅记录当前实际入口、页面操作、已有真实请求、实际参数范围和业务结果，不再表示等待研发冻结PRD接口。接口专项必须先有页面发出的请求或当前已实现服务入口，再构造对照数据；不要按需求拼端点/字段/错误码。

保存成功用真实内容刷新核对；任务完成用对应文件/字幕/声音核对。当前没有拟定内部接口不构成页面失败；已确认的业务功能缺失仍记未实现，不能自动排除。未公布数值限制仅记录业务边界，不套需求建议值。

## F 故障与竞争前置操作

使用本例可复现真实失败、断网/恢复、关闭重开、双标签保存、接近完成取消及迟到结果。无需数据库、投递表、租约、内部锁或专用后端注入点；不能复现则记对应分支未覆盖及原因，不故障共享服务、不修改云端代码。

前端响应模拟只证明展示，不计真实保存/取消/计费通过。响应未知时，重新读取可能得到完整旧内容或完整新内容，应按实际接收情况核对，不武断要求服务端回滚。

## PCLEAN独立词句和声音金标

K1为源9～10秒已核验可删1秒区间；先听审/看源并登记金标，没有则制备，不能用模型临时选择自证。词句依据独立原音频/文字，不要求真实接口提供逐字映射。

| 变体 | 业务核验 |
|---|---|
| CWORD | 8～12秒跨删除边界句子，删9～10秒后按人工金标核对真实保留词和声音；不强制中点/半开区间或派生ID算法 |
| CNOWORD | 输入无可用逐词结果，但有原音频/句子标准；正确处理或明确先拆分/确认，不能猜错却报成功，也不因缺拟定字段直接判失败 |
| CBOUND | 8～9秒、10～12秒两句，中间空隙9～10秒；删除后第二句声音/字幕前移1秒，文字不变 |
| CBILINGUAL | 两语言和配音可区分，其中一项难以对齐；两语/声音都正确或明确不能完成，不能只改一部分 |

草稿例检查无静默丢稿、无串对象、无自动发送或重复应用。PT首次原文关/译文开与用户手动两语都开分别验证，切页不重置明确选择。未确认的业务边界仅记录，未公开内部设计不构成前置阻塞；已确认页面功能缺失仍记录实际未实现。

每例记录入口/子页、播放位置、目标、完整指令、澄清、真实页面/响应、刷新后内容、文件及截图。Web/macOS分开记录，单端不能代替另一端。
