## 当前统一业务规则

1. 用户已确认[最新主页面](https://www.figma.com/design/SqGzwtxqNjFZa9QIvUPAlc/Workspace-System---Design?node-id=1501-27245)为Media、Scripts、Captions、Voiceover、Watermark五入口。旧六TAB及待定方案不作为本轮导航标准；实际混音控件不虚构第六Audio入口。
2. 工程、会话、源素材、任务及导出文件分别辨识，按真实内容和归属核对，不强制它们使用需求指定字段。输入素材不等于写入目标，切页/上传/后台完成不擅自改目标。
3. 明确对象可通过现有选择或工程/原文/时间描述，不强制引用标签。196-002范围分页、004旧引用交互按用户决定仍不适用；005换成明确字幕位置后改文，原Blocked撤销但尚未重跑。
4. 同一业务的复合修改、撤销、并发保护和恢复要看真实结果；不要求哪种错误码、提交次数、历史组、事件序号或数据库/缓存/锁实现。
5. 首次译制原文关/译文开的评论业务，与用户手动两语都开分别核对；字幕显示不等于删除/静音，切页不能重置用户明确选择。
6. 草稿、对象受限和清理边界按当前已确认用户交互与独立声字金标验收。不把拟定四维草稿键、逐词中点/半开区间算法或缺少接口逐字字段当失败理由；实际删错词、声音残留或静默丢稿仍是业务问题。
